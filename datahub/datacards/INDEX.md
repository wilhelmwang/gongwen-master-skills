# 语料数据卡（Data Cards）

本包**对外分发时不含任何语料**。本目录说明每份语料的来源、字段、口径与许可定性，
并给出**可复现的取数命令**——使用者按卡自行取数。

写法参照 Datasheet for Datasets（Gebru et al., arXiv:1803.09010）的核心要素：
动机 → 构成 → 采集过程 → 标注 → 用途 → 分发 → 维护。
卡片是数据的**指针层**，不是数据本身。

**取数入口**：`python datahub/fetch_corpus.py --what <名称>`（打印命令，不代跑）

## 2. 公文范文池 `samples`

| 项 | 内容 |
|---|---|
| **来源** | 全国省/市/县三级政府门户与厅局子站**公开发布**的公文 |
| **域名底座** | 5,080 个（省级门户 31 + 二级门户 94 + 三级子站 4,986）；挖掘器 `mine_domains.py` / `mine_counties.py` 从省级门户逐级下挖 |
| **已验证规模** | 24,031 篇（2026-09-28 实测）：调研报告 5,792 / 工作报告 5,089 / 会议纪要 5,084 / 消息 5,007 / 工作总结 3,059 |
| **落盘位置** | 数据根 `govdoc_samples/collected.jsonl`（唯一事实源）+ `gongwen_samples.db`（派生物） |
| **三层结构** | `raw_pages` L0 原始层（清洗前原文 + `raw_sha256` + `clean_version`）/ `samples` L1 治理层（`content` `skel` `txt_hash` `clean_version` + trigram FTS）/ `review_state` L2 审核台账（`review_kind` `tier` `payload_json` `need_full`） |
| **已知限制** | ① L1 正文仍含网页框架文字（实测约 18%，含站点页脚与 CMS 侧栏）；② 存量 1,203 篇无 L0（重抓失败或重抓抽取不足），`clean_version=legacy_no_raw`；③ **按正文相似度做近重复判定在本语料上不成立**——政府公文高度模板化，不同县/不同次/不同日期的正式文件包含率仍达 0.93–1.00，故只做精确重复标记（625 篇） |
| **复现** | `probe_fast.py --all`（三跳发现）→ `sweep_deep.py --phase cols`（深翻）→ `build_samples_db.py`（建库）→ `dedup_samples.py`（标重复）；缺失原文用 `refetch_raw.py` 按 URL 重抓补 L0 |
| **许可** | 政务公开文件，**行政性质，不适用著作权保护**；须保留 `url`/`source_key`/`fetched_at` |
| **注意** | 对外交付前应先清理网页框架文字，否则会把站点导航当作范文内容一并分发 |

- 本目录属**知识层**（说明文档），不含数据本体

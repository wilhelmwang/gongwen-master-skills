## 一、它是什么 / 不是什么

**是**
- 一个读了求是三源 5,761 篇（《求是》+《红旗文稿》+求是图书，2018-2026）的写作专家角色
- 基于真实统计规律的公文方法论（结构/开头/结尾/论证/修辞走频率最高处）
- 配套全文检索数据库（qiushi.db），需要引真实范文时可查

**不是**
- 不是万能填空模板（机械套用必翻车）
- 不是政策事实数据库（求是文章是范本，政策时效请以官方最新文件为准）
- 不会替你拍板政治站位（重大文稿务必以所在单位的审核为准）

## 二、五类用法（怎么触发）

### 1. 写（从零到稿）
> 一句话给主题 + 场合 + 受众即可。
```
帮我写一篇全区数字经济工作会议讲话，五分钟发言，受众是各局办和街道负责人
```
大师会：定调（对标中央数字经济部署）→ 立骨（总分总：形势→任务→举措→保障）→ 起笔（论断破题）→ 四柱论证 → 排比润色 → 收口。

### 2. 改（对症优化）
> 把文稿贴进来，指明痛点。
```
这份工作总结空话太多、没有数据，帮我按求是体改一版，结尾要有号召力
```
大师四维体检：政治性 / 规范性 / 逻辑性 / 鲜活性，给修改前后对照。

### 3. 评（打分点评）
```
点评我的发言稿：结构、开头结尾、论证强度、语言风格各给分，附一句最该改的地方
```

### 4. 仿 / 学（看它怎么写）
```
按求是《署名文章》的风格，把这段理论阐释写得更"有领导味"
```
```
求是文章通常怎么处理"问题-原因-对策"段？各举一个开头句子的写法规格
```

### 5. 查（引真范文）
```
查求是库里有关于"新质生产力"的文章，摘一段论述可作引用的开头
```

## 三、让它发挥全力的五个设定

1. **说清文种**：讲话/报告/发言/心得/解读/部署——不同文种骨架不同。
2. **说清受众**：上级汇报 vs 下级动员 vs 平级交流，语气差异大。
3. **给足背景**：本地案例、数据、会议要求——喂得越多越实。
4. **指定长度与场合**：5 分钟 vs 半小时，书面 vs 口头，直接影响结构密度。
5. **迭代而非一次成型**：先出骨架→你确认→再填肉→再润色，比"一次写到位"质量高。

## 四、输出规范（大师默认遵守）

- **政治标准**：立场正确，对标中央精神，引用领袖论述准确规范
- **结构标准**：骨架清晰、层层递进、首尾呼应、衔接自然
- **语言标准**：规范准确、简洁有力、庄重大方、无口语化
- **内容标准**：数据/案例/论述四柱齐备，鲜活有温度，杜绝空泛套话
- **格式标准**：符合 GB/T 9704 公文格式习惯

## 五、五步沟通法（推荐最小工作流）

| 步 | 你说 | 大师做 |
|---|---|---|
| 1 | "写一篇 XX（文种）" + 主题 | 定调、给结构骨架 |
| 2 | "按这个骨架填"（或微调） | 分节填充正文 |
| 3 | "换个开头/结尾" | 按统计规律替换起收 |
| 4 | "数据/案例不够" | 补论证四柱 |
| 5 | "帮我检查一遍" | 四维质检 + 修改建议 |

## 六、常见问题

**Q：AI 写的会不会太"模板感"？**
A：因为主干走的是求是三源 5,761 篇统计中频率最高的打法（总分总+引领袖讲话+总结升华），天然接近官方文风；但素材要靠你给，空对空才会空泛。

**Q：涉及具体政策/数据怎么办？**
A：把口径交给你所在单位的成文依据。技能只保证"写得好"，不保证"数据最新"。

**Q：想让它像某位领导/某篇范文的风格？**
A：给一段样本文字让它先"拆解风格"再仿写——技能具备风格仿写能力。

**Q：触发词有哪些？**
公文大师、写公文、公文写作、领导讲话、工作报告、政策文件、求是体、发言稿、心得体会。

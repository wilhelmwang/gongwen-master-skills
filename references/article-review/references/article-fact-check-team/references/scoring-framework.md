# 多维度评分框架 V3.1

> 本文档定义"文章核查专家团"的七维度评分标准、加权计算方法、评级区间和不同类型文章的评分参考。
>
> **V3.1 更新**：补充了与"组件级信任评分"、"证据覆盖度"、"时效衰减系数"的对应映射关系。

---

## A. 七维度评分标准

**使用规则**：
- 每维度 10 分制，按下方标准打分
- 每条评分附加置信度标记（🔵 高 / 🟡 中 / ⚪ 低）
- 仅当有充分外部验证依据时标记 🔵 高

### A.1 事实准确性（权重：25%）

评估文章引用的数据、数字和事实性陈述的准确性。

| 分数 | 标准 |
|------|------|
| 10 | 所有核验数据点全部准确，无内部矛盾，数据来源完全可追溯 |
| 8-9 | 主要数据准确，有 1 处轻微偏差或数据源标注不清 |
| 6-7 | 主要数据大致准确，但有 1-2 处实质性错误或内部不一致 |
| 4-5 | 存在多处数据错误或关键数据不可验证 |
| 1-3 | 大量不实数据或系统性误导 |

**典型扣分项**：
- 内部数据不一致（同一文章不同地方写不同数值）→ -2
- 关键数据与外部验证结果明显不符 → -3~-5
- 数据来源无法追溯 → -1~-2
- 数据时点与论证场景不匹配 → -1~-2

**与 Phase 2 的对应关系**：
| Phase 2 核查结果分布 | 推荐评分 |
|---------------------|---------|
| 所有声明均为 ✅ | 9-10 |
| 少量 ⚠️ 偏差 | 7-8 |
| 有 ❌ 错误 | 4-6 |
| 大量 ❌ 或 ❓ | 1-3 |

### A.2 逻辑严谨性（权重：25%）

评估推理链条的完整性、归因合理性和论证结构。

| 分数 | 标准 |
|------|------|
| 10 | 推理链完整严密，归因考虑了多因素，讨论了替代解释 |
| 8-9 | 推理链基本完整，归因合理但略偏简化 |
| 6-7 | 推理链有中断或跳跃，归因偏单一 |
| 4-5 | 存在明显的逻辑谬误或重大归因问题 |
| 1-3 | 逻辑混乱，基本没有有效推理 |

**检查清单**：
- [ ] 前提→结论的链条是否完整，有无跳跃
- [ ] 因果关系是否充分考虑了混杂因素
- [ ] 是否讨论了替代解释或反方观点
- [ ] 是否将相关关系充当因果关系
- [ ] 关键术语的定义是否一致
- [ ] Warrant（推理假设）是否隐含了不合理的先决条件

**与 Phase 3 的对应关系**：
| Phase 3 逻辑强度总评 | 推荐评分 |
|--------------------|---------|
| 四项 ★★★★★ | 9-10 |
| 多数 ★★★★☆ 以上 | 7-8 |
| 存在 1 项 ★★★☆☆ | 5-6 |
| 存在高严重度谬误 | 3-4 |
| 多处高严重度谬误 | 1-2 |

### A.3 信息来源质量（权重：15%）

评估文章引用的数据来源的可信度和透明度。

| 分数 | 标准 |
|------|------|
| 10 | 来源全部为官方一手数据或权威专业平台，完全可追溯 |
| 8-9 | 主要来自权威来源（官方/国家级媒体/专业数据平台），少数来自二手 |
| 6-7 | 来源混杂，有权威来源也有不可追溯来源，但核心数据来自可查证渠道 |
| 4-5 | 核心数据依赖匿名来源、单一信源或信源有利益关联 |
| 1-3 | 关键数据来源完全不明，大量"业内人士"等不透明引用 |

**与 Phase 2 来源评估的对应关系**：
| 星级分布 | 推荐评分 |
|---------|---------|
| 核心数据来源 ≥ ★★★★★ | 8-10 |
| 核心数据来源 ≥ ★★★★☆ | 6-8 |
| 主要来源 ≤ ★★★☆☆ | 4-6 |
| 主要来源 ≤ ★★☆☆☆ 或不可追溯 | 1-3 |

### A.4 框架创新性（权重：10%）

评估文章是否提供了超出日常报道的增量洞见。

| 分数 | 标准 |
|------|------|
| 10 | 提供了全新的分析框架或前瞻性洞见 |
| 8-9 | 有实质性增量信息，框架有独到之处 |
| 6-7 | 有一定增量信息，但大部分是事件描述的重组 |
| 4-5 | 信息增量有限，主要是事件复述 |
| 1-3 | 完全没有增量信息，甚至是已知信息的浓缩 |

### A.5 信息时效性（权重：10%）

评估内容的时间价值。

| 分数 | 标准 |
|------|------|
| 10 | 事件发生后数小时内发布 |
| 8-9 | 事件发生当天或次日 |
| 6-7 | 事件发生后数日内 |
| 4-5 | 事件发生后一周以上 |
| 1-3 | 过时信息或已知旧闻 |

**注意**：分析类/研报类文章的通病是时效性评分天然偏低（分析需要时间），按实际发布时间评分即可。

### A.6 生产透明度（权重：10%）

评估作者/机构的背景透明度、编辑独立性和利益冲突披露。

| 分数 | 标准 |
|------|------|
| 10 | 明确披露作者背景、编辑审查流程、资金来源、潜在利益冲突，数据来源完整标注 |
| 8-9 | 机构背景透明，编辑流程可查，但利益冲突未明确说明 |
| 6-7 | 机构背景可查但未主动说明，编辑流程不透明 |
| 4-5 | 来源模糊，难以判断背景和立场 |
| 1-3 | 来源明显有偏但伪装成独立分析，或完全匿名 |

**评估内容**：
- 作者/机构背景与资质
- 编辑审查流程披露
- 资金来源与业务模式
- 数据来源标注完整性与可追溯性
- 意识形态平衡程度（是否只呈现单方视角）
- 潜在利益冲突的披露情况

### A.7 可读性与结构性（权重：5%）

评估文章的观点清晰度、结构合理性和表达质量。

| 分数 | 标准 |
|------|------|
| 10 | 结构清晰、观点鲜明、表达精准 |
| 8-9 | 结构合理、观点明确、表达良好 |
| 6-7 | 结构一般、观点较分散、表达有可优化处 |
| 4-5 | 结构松散、观点不明确、表达混乱 |
| 1-3 | 完全无序，无法阅读 |

## B. 置信度标记

每条维度评分附加置信度标记：

| 标记 | 含义 | 条件 |
|------|------|------|
| 🔵 **高** | 有充分证据支持该评分 | 至少 2 个独立来源交叉验证通过 |
| 🟡 **中** | 有部分证据，但存在不确定性 | 仅有单一来源验证，或来源存疑 |
| ⚪ **低** | 主要凭分析者判断，缺乏外部验证 | 无法找到独立来源，或数据存争议 |

**示例**：
> 事实准确性：8/10 (🔵 高——已验证 3 个数据源一致)
> 逻辑严谨性：7/10 (🟡 中——推理链完整但归因有偏简倾向)

## C. 综合评分计算

### C.1 加权公式

**综合 = 事实准确性×25% + 逻辑严谨性×25% + 信息来源质量×15% + 框架创新性×10% + 信息时效性×10% + 生产透明度×10% + 可读性×5%**

### C.2 简化速算

不必精确计算，按感知加权快速判断：
- 如果事实准确性和逻辑严谨性**都 ≥8** → 通常可信度在 7.5+
- 如果其中一项 **≤5** → 最高不会超过 6.5（两项占 50%）
- 信息来源质量为 ★★ 以下 → 事实准确性不可能超过 7

### C.3 评级区间

| 等级 | 标签 | 综合评分 | 含义 |
|------|------|---------|------|
| 🟢 **高** | 可信 | ≥8.5 | 数据准确、逻辑严密、来源可靠、透明度高 |
| 🟡 **中高** | 大部分可信 | 7.0-8.4 | 数据基本准确、有少量缺陷 |
| 🟡 **中等** | 部分可信 | 5.0-6.9 | 存在明显数据或逻辑问题 |
| 🟠 **低** | 需谨慎 | 3.0-4.9 | 核心数据或逻辑存在严重问题 |
| 🔴 **不可信** | 不建议采信 | <3.0 | 大量不实数据或明显误导 |

## D. 金融投资类附加风险评级

对于金融投资类文章，额外附加"投资建议风险"独立评级（不参与加权计算）：

| 等级 | 含义 |
|------|------|
| 🟢 低风险 | 有合规声明、投资资质可查、无情绪化修辞 |
| 🟡 中风险 | 缺少风险提示或存在部分情绪化表达 |
| 🔴 高风险 | 存在 Pump-and-Dump 信号或明显的利益冲突 |

## E. 不同文章类型的评分参考

| 文章类型 | 典型范围 | 说明 |
|---------|---------|------|
| 官方机构报告（央行/统计局） | 8.0-9.5 | 数据权威，但可能有政策导向偏差，时效性通常较低 |
| 深度财经媒体（财联社/路透） | 7.5-9.0 | 时效性高、信源广泛，但深度分析可能有限 |
| 卖方研究报告（券商研报） | 6.5-8.5 | 专业但存在利益冲突，结论常偏乐观 |
| 头部专业自媒体 | 6.0-7.5 | 有信息渠道和逻辑框架，但需防叙事倾向 |
| 行业垂直号 | 4.5-6.5 | 专业但可能带利益立场 |
| 营销号/AI 洗稿号 | 1.0-4.0 | 数据质量差，需全面核查 |
| 个人观点/博客 | 3.0-6.0 | 取决于作者的专业背景和数据引用质量 |

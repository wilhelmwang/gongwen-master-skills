## 八、核心能力
- 结构设计：总分总立骨、并列展开、递进纵深、问题导向、历史-现状-展望五型切换
- 语言表达：庄重规范、长短句结合、排比提气、对仗工整、数字具象
- 论证说理：领袖论述定调 + 典型案例实证 + 历史纵深开合 + 数据支撑量化
- 风格把握：署名文章/理论阐释/评论述评/经验提炼/实证调研/动员部署/政策解读/综合论述八型切换
- 起收技巧：开头引领袖讲话/背景切入/论断破题，结尾总结升华/号召展望/部署要求
- 质量把控：政治性、规范性、逻辑性、鲜活性四维度审查

## 九、写作流程（六步法）
- 1. 定调：背景与主题研判，确立政治站位（对标中央精神）
- 2. 立骨：选结构骨架（默认总分总，按文体切换并列/递进/问题导向）
- 3. 起笔：按文体选开头（论述文引领袖讲话/决策部署用论断破题/调研文背景切入）
- 4. 填肉：四柱论证——领袖论述+典型案例+历史纵深+数据支撑
- 5. 润色：排比对仗比喻修辞，锤炼大小标题，长短句穿插
- 6. 收口：总结升华+号召展望落点实，写法收尾不悬空

## 十、质量标准
- **政治性**：立场正确，对标中央精神，引用领袖论述准确规范
- **规范性**：文体合规，用语庄重无口语化，引用/数字无误
- **逻辑性**：骨架清晰，层层递进，首尾呼应，段落衔接自然
- **鲜活性**：有数据有案例有温度，杜绝空泛套话

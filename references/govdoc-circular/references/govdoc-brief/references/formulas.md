# 信息写作公式

## 动态信息

动态信息=标题+做法句+成果句（具体数据）

写法要点：一段话讲清一个亮点，避免展开成总结。

## 经验信息

经验信息篇章=主标题+正文段1（小标题1+做法句+成果句）+正文段2（小标题2+做法句+成果句）+……
主标题=地区/单位+主题+效果词
正文段=小标题+核心做法+关键数据/成果

## 提示词骨架

```text
你是【单位】办公室工作人员，擅长撰写政务信息。请结合【工作材料】，按照【动态信息/经验信息写作公式】撰写一篇信息。要求突出亮点、数据准确、语言简洁，字数为【】。
```

## 分步策略

- 材料杂乱时，先让AI按“做法、成果、数据、可推广经验”归类。
- 动态信息只保留最强亮点。
- 经验信息先拟3个对仗小标题，再填充做法和成果。

# 通用公式与提示词骨架

## AI辅助公文写作七步法

1. 拆解工作问题：明确要解决什么事、写给谁、用于什么场景。
2. 分析处理信息：搜集政策、数据、案例、领导要求和单位材料。
3. 判断信息质量：核验准确性、时效性、相关性和适用性。
4. 明确写作要求：确定文种、观点、结构、语气、篇幅。
5. 生成文本内容：简单文种整篇生成，复杂文种分部分生成。
6. 判断内容质量：检查结构、观点、逻辑、语言、事实、合规。
7. 精调文本内容：改标题、改段落、补数据、压缩、扩写、换语气。

## 通用提示词框架

```text
你是【单位/行业】【身份】，熟悉【政策/业务/材料写作能力】。
【宏观背景】为贯彻落实……
【微观背景】当前需要……
【受众背景】材料将用于……，阅读/听取对象是……
【任务】请你……
【要求】1. 内容必须包含……；2. 结构按照……；3. 语言风格……；4. 字数……；5. 输出方式……。
```

## 四个提示词要素

角色=单位+身份+能力

- 单位：写清公文材料涉及的行业单位类别，如政府部门、事业单位、国企央企、学校、医院等。
- 身份：常用办公室主任、领导职务、领域专家等身份，让AI明确写作视角。
- 能力：补充“熟悉政策文件”“擅长公文材料写作”“了解业务发展路径”等能力约束。

背景分三类：

- 宏观背景：上级政策精神、当前形势、工作要求。
- 微观背景：为什么有这个任务，要解决什么具体问题。
- 受众背景：材料写给谁、讲给谁、用于什么场合。

任务分两类：

- 文本输出任务：简单文种可整篇输出，复杂文种应按标题、提纲、段落或部分逐步输出。
- 构思任务：用于复杂材料的信息搜集、问题拆解、提纲生成、观点提炼；不清楚该问什么时，可让AI反向提问。

要求分两类：

- 内容要点：明确必须写入的观点、事实、数据、政策、领导要求。
- 内容结构：用写作公式或内容模块框定篇章结构和段落句式。

## 写作公式用法

公式用于框定结构，不替代事实判断。先把公式拆成“篇章结构”和“段落句式”，再把用户提供的事实、政策、数据和观点填入。

## 内容模块用法

当某类段落难写，如问题段、帽段、结尾段，可先提炼优秀段落的抽象模板，再让AI按模板填入当前工作内容。

内容模块三步：

1. 选择可拆解段落：找一段同类材料中质量高、分寸准的段落。
2. 提取内容模块：去掉具体工作内容，保留句式、语气、层次和常用表达。
3. 放入提示词：要求AI按模块填入当前工作事实，再由人工删改不贴合处。

## 调试提示词

- 修改提示词：补充角色、背景、内容要点、结构公式或字数。
- 指出问题：告诉AI哪一部分空泛、偏题、语气不对或缺少数据。
- 重新生成：同一要求生成2-3版，择优组合。
## 分步策略

- 信息不足时，先列出必须补充的关键项；用户要求直接写时，基于已知信息作保守假设。
- 简单材料可一次生成；复杂材料先生成提纲或要点，确认后分部分扩写。
- 生成后按事实依据、结构完整、语言风格、可执行性和风险边界逐项检查。

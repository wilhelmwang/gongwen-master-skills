# 以稿写稿（材料摄取与重组 · govdoc-material v1.0.0）

## 角色定位

用户手里有材料、缺成稿。你的活是**把散落的事实搬运成一篇合规公文**，而不是创作。

**核心约束：你搬运，不发明。** 材料里没有的事实、数字、提法，一律不许补——宁可在成稿里留
【待补】标记交回用户，也不许写一个看起来合理的数。

## 与相邻技能的分工（重要，别做错事）

| 用户的处境 | 该走谁 |
|---|---|
| 只有零散材料，要成一篇公文 | **本技能** |
| 已有成稿，要润色/改写/扩写/精简/质检 | `govdoc-polish` |
| 没有材料，凭空写某文种 | 对应 `govdoc-*` 文种技能 |
| 材料里含本地数据（地方/本市统计）需要取数 | 先 `qiushi-db` 取数，再回本技能 |
| 材料是历年公文，要学本单位文风 | `govdoc-corpus`（单位语料接入） |

## 工作流

### Step 1 收料与登记

先确认清单再动手。逐份登记：**文件名 / 格式 / 大致内容 / 是否可用**。

- 材料格式若非纯文本（`.docx` / `.doc` / `.pdf` / `.xlsx` / `.pptx`），**先调 `convert-documents-to-markdown`
  技能转成 Markdown** 再解析。不要凭文件名猜内容。
- 任一材料无法解析（扫描件、加密件、格式损坏）→ **显式报出跳过**，不得静默忽略。
- **涉密提示（必做）**：若材料可能涉密，先提示用户——
  「本流程中若需调用 LLM（团队模式评审 / 质检增强），会把文本发往外部端点；涉密材料请只用
  本地确定性能力，或告知我改用不外发的方式。」（依据见 `gongwen-master` 合规交付·涉密不上网）

### Step 2 解析与标注

把每份材料转成可引用的**分块**，给每块一个稳定编号（如 `M1-§3`），供溯源表引用。
编号必须能被用户回溯到原文位置。

### Step 3 要素抽取（六类）

按 `references/element-extraction.md` 的规则抽取六类要素。**逐条记来源**：

| 类别 | 抽什么 | 常见坑 |
|---|---|---|
| 时间 | 时点、期限、阶段划分 | 材料里的"去年/近期"要换算成具体年份，换算依据也要标来源 |
| 数字与指标 | 数值、单位、口径、同比 | **口径（统计范围/年份）必须一起搬**，缺口径的数字等于没有 |
| 事项与举措 | 做了什么、怎么做、谁负责 | 把"拟办/已办/待办"的时态分清，别把计划写成成效 |
| 主体与机构 | 单位全称、部门、职务、人名 | 简称要还原为首次出现用全称；人名职务以材料为准 |
| 政策口径与提法 | 引用的政策名称、领导论述、固定表述 | 提法要照抄，不得同义改写（改了就变味） |
| 成效与问题 | 结果、数据支撑、存在不足 | 缺数据支撑的"成效"标为定性表述，不得渲染成量化成绩 |

### Step 4 按目标文种重组

1. 确认**目标文种**（用户说了就用；没说则问，或用 `gongwen-master` 路由判定）。
2. 读该文种技能的体例公式文件（形如 `../govdoc-report/references/formulas.md`），按公式的构件顺序摆放要素。
3. 材料有富余时按文种体例裁剪；材料不足时**留空并标【待补】**，不要用套话填满。
4. 语言风格按目标文种；需要特定文风时按用户指定，不擅自套用。

### Step 5 输出要素溯源表（**本技能的核心交付物**）

成稿之后必须附溯源表，格式见 `references/provenance-table.md`。最低要求：

- 每条**事实性内容**（数字、时间、机构名、政策名、领导论述）都能在表里找到来源
- 来源写成「材料编号 + 位置（章节/段落）」
- 无法确认来源的 → 单独列一节【待补】，写清"缺什么、向谁确认"

### Step 6 自检（过一遍再交）

- [ ] 成稿里每个数字都能在溯源表里找到对应行
- [ ] 没有把 A 材料的成绩安到 B 主体头上（跨材料张冠李戴是最常见的失真）
- [ ] 政策名称/领导论述是**原样照抄**，没有同义改写
- [ ] 数字带口径（统计范围 + 年份）
- [ ] 【待补】项没有被我偷偷用估算值填上
- [ ] 涉密提示已给（若材料可能涉密）

## 红线（不可越）

1. **不得凭空生成事实。** 材料里没有的数字、时间、机构、提法，一律不许补。这是本技能存在的意义。
2. **不得把计划写成成效。** 材料说"拟于 X 月完成"，成稿不能写成"已全面完成"。
3. **不得同义改写政策提法。** 提法照抄；确有冗长需精简时，只压语气词，不动核心表述。
4. **不得替用户决定口径。** 同一指标材料里有两个口径时，问用户或并列标出，不自行选一个。
5. **不得省略不可解析的材料。** 跳过了哪些、为什么跳过，必须写在交付说明里。

## 交付格式

```
【成稿】
（按目标文种体例的正文）

【要素溯源表】
（见 references/provenance-table.md 格式）

【待补项】
（缺什么、为什么缺、向谁确认）

【交付说明】
（用了哪些材料；跳过哪些材料及原因；是否涉及涉密提示）
```

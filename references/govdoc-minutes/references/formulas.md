# 会议纪要写作公式

## 办公类会议纪要

纪要篇章=标题+引言段+议题段1+议题段2+议题段3+……
标题=会议名称+纪要
引言段=会议时间+主持人+会议地点+会议名称+会议传达/听取/审议/通报事项+重点研究事项+参会领导
议题段常用动词=会议指出/会议强调/会议要求/会议决定/会议明确/会议号召

## 研讨协商类会议纪要

纪要篇章=标题+引言段+正文段（会议过程）+正文段（观点/共识）+正文段（结论要求）

## 提示词骨架

```text
你是【单位】办公室工作人员，熟悉会议纪要写作。请结合【会议记录】，按照【会议纪要写作公式】撰写一篇【办公类/研讨协商类】会议纪要。要求议题不遗漏，按记录顺序撰写，保留关键细节，使用规范纪要动词。
```

## 分步策略

- 记录很长时，先提取“基本信息、议题、决定、要求、分工”。
- 决策类纪要突出“议定事项”和“落实要求”。
- 研讨类纪要突出“讨论过程、主要观点、形成共识”。

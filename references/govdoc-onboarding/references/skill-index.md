## 五、易混淆文种区分（速查）

- **通知** = 布置要做的事（向前看）→ `govdoc-notice`；**通报** = 评价已发生的事 → `govdoc-circular`
- **总结** = 单位回顾 → `govdoc-summary`；**述职** = 个人履职 → `govdoc-report`；**调研报告** = 有过程有数据 → `govdoc-research`
- **公开信** = 情感导向 → `govdoc-letter`；**消息** = 信息导向 → `govdoc-news`
- **讲话** = 领导对下级 → `govdoc-speech`；**纪要** = 会议整理 → `govdoc-minutes`
- **批复试** = 上级回复 → `govdoc-approval`；**请示** = 下级请求 → `govdoc-request`

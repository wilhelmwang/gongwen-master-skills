# 制度 · 规定 · 办法 写作公式

> 适用文种：制度、规定、办法、实施细则、工作规程、守则、章程
> 说明：本技能此前 SKILL.md 声称「按公式生成初稿」但**未随包 formulas.md**（v7.3.1 补齐）。

## 一、通用公式

规范性文件篇章=标题+总则部分+分则部分+附则部分
标题=【单位】关于【事项】的【制度/规定/办法/实施细则】
总则=制定目的句+制定依据句（上位法规全称与文号）+适用范围句+基本原则句+管理职责句
分则=按管理链路分解：对象与标准 → 程序与流程 → 权利义务 → 监督与考核 → 责任与追究
附则=解释权句+施行日期句+原规定废止句+过渡条款句

## 二、分类公式

### 制度（综合性 · 长效）

制度篇章=总则+组织与职责+工作内容与标准+工作程序+考核与奖惩+附则
要点：覆盖面广、稳定性强，须写明组织架构与各方职责边界。

### 规定（事务性 · 约束性）

规定篇章=总则+具体规定（分条列项）+违规处理+附则
要点：针对单一事项作出明确约束，**必须有可执行的违规处理条款**。

### 办法（操作性 · 程序性）

办法篇章=总则+办理条件+办理程序（申请→受理→审核→决定→送达）+时限规定+监督+附则
要点：程序写清「谁在几个工作日内做什么」，时限用「工作日」而非「天」。

### 实施细则（上位法落地）

实施细则篇章=总则（写明所实施的上位法名称与文号）+逐条对应细化+补充规定+附则
要点：条款编号尽量与上位法条序对应，便于对照适用。

## 写作红线

- **条款必须可执行**：写清「谁、做什么、依据什么、违反后果」，不写无法执行的倡导性表述。
- **不与上位法冲突**：引用依据须写全称与文号（如《党政机关公文处理工作条例》（中办发〔2012〕14 号））。
- **术语前后一致**：同一概念全文只用一种叫法，禁止同义替换。
- **罚则须有依据**：不得自行创设行政处罚；处理措施限于上位法授权范围。
- **禁用模糊限定**：不用「原则上」「一般情况下」「视情」等（确有例外必须写明例外条件与判定主体）。
- **解释权与施行日期必备**：附则缺这两项即不完整。

## 提示词骨架

```text
你是【单位】负责制度起草的工作人员，擅长规范性文件写作。请按照【制度/规定/办法/实施细则写作公式】，结合【管理事项与上位依据】，起草一份【文种】。要求：条款可执行、依据写全称与文号、术语一致、无模糊限定、罚则有上位法依据、附则含解释权与施行日期，字数为【】。
```

## 分步策略

- 信息不足时，先列出必须补充的关键项（上位依据全称与文号、管理主体、审批权限、施行日期、原有规定的废止范围）；用户要求直接写时，对不全项以【待补】占位并显式提示。
- 复杂制度先生成「章—条 标题框架」，确认后再逐条成文，避免整篇返工。
- 生成后按依据合法性、条款可执行性、术语一致性、与上位法兼容性、附则完整性逐项检查。
- 重大制度或涉处罚条款，建议走团队模式派**法鉴**复核合法性（规则 F / 显式要求）。

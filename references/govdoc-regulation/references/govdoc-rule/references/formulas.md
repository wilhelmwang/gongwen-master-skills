# 规章制度写作公式

## 三阶段流程

1. 找依据、抓重点：分析管理问题，检索上位文件和同类制度。
2. 定框架、明要点：根据问题和依据列出制度章节、职责、流程、监督。
3. 写内容、查合规：分章条生成，逐章细化，最后核对依据和冲突。

## 常见制度结构

制度篇章=总则+职责分工+管理范围/对象+工作流程+监督检查+责任追究+附则
总则=制定目的+依据+适用范围+基本原则
职责分工=主管部门职责+协同部门职责+执行单位职责
流程条款=申请/审批/执行/备案/监督/整改
监督责任=检查方式+问题整改+责任追究
附则=解释权限+施行日期

## 提示词骨架

```text
你是【单位/部门】负责人，熟悉【领域】管理要求，擅长撰写规章制度。请结合【管理问题】和【依据文件】，列出【制度名称】框架要点。要求章条逻辑清晰、职责明确、流程可执行。
```

```text
请依据【已确认制度框架】撰写【制度名称】。要求采用章条式写法，条文排列严谨有序，概念准确，要求明确具体，字数为【】。
```

```text
请检查以下制度草案是否存在与【依据文件】冲突、职责不清、流程不可执行、概念不一致的问题，并提出修改建议。
```

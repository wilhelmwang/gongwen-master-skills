# 报告类公文写作公式

> 适用文种：工作报告、述职报告、专项工作报告、履职情况报告
> 来源说明：述职报告部分原误置于 `govdoc-duty/references/formulas.md`
> （该技能实际文种为任免通知），v7.3.0 归位至本技能——述职报告属报告类公文。

## 一、工作报告

工作报告篇章=标题+帽段+总体情况段+主要工作与成效部分+存在问题与不足部分+下一步工作安排部分

标题=关于【事项】的报告 ／ 【期间】工作报告
帽段=依据句（根据/按照…要求）+时限句（现将…报告如下）+过渡句
总体情况段=总体判断句+核心指标句+形势定位句
主要工作与成效部分=分类标题+举措句+数据成果句（每一类一段，2-4 类）
存在问题与不足部分=问题表现句+原因分析句（问题须具体可改，忌空泛）
下一步工作安排部分=目标句+重点任务句+保障措施句
落款=报告单位+日期

## 二、述职报告

### 员工述职报告

员工述职报告篇章=标题+帽段+工作业绩与亮点部分+个人能力与素质提升部分+存在问题与改进措施部分+下一步工作展望段
标题=202X年度述职报告
帽段=岗位职责句+年度工作背景句+工作定位与理念句+自我评价句+过渡句
工作业绩段=工作事项标题+职责对应句+做法句+成果句
能力提升段=学习成长句+实践锻炼句+能力变化句
问题改进段=问题表现句+原因分析句+改进措施句
个人能力与素质提升部分=理论学习段+专业技能段+党风廉政段
存在问题与改进措施部分=问题分析段1+问题分析段2+问题分析段3+问题分析段4（3-4个问题段）
下一步工作展望段=工作规划段+个人职业发展愿景段

### 领导述职报告

领导述职报告不固定套用通用篇章公式，基本依据是上级关于述职的通知和领导确认的述职提纲。写作时必须先分析上级通知要求，再围绕领导工作实际生成提纲，经确认后成文。

领导述职流程=分析上级通知要求+梳理领导意图和工作情况+生成述职提纲+按确认提纲撰写+检查是否遗漏通知要求

常见内容=履职情况+重点工作成效+党建/廉洁/队伍建设要求+存在问题+下一步打算。具体取舍以上级通知为准。

## 三、专项工作报告

专项工作报告篇章=标题+帽段+专项背景段+工作开展情况部分+专项成效部分+问题与建议部分+结语

标题=关于【专项事项】的报告
帽段=依据句+专项范围句+过渡句
专项背景段=上级部署句+本级实际句
工作开展情况部分=组织部署段+推进举措段+协同配合段
专项成效部分=定量数据句+定性判断句+典型案例句
问题与建议部分=问题段+原因段+建议段（建议须可执行）

## 提示词骨架

```text
你是【单位/岗位】工作人员，擅长报告类材料写作。请按照【工作报告/述职报告/专项工作报告写作公式】，结合【工作情况与数据】，撰写一份【文种】。要求结构清晰、数据准确、成绩不夸大、问题不回避，字数为【】。
```

## 分步策略

- 信息不足时，先列出必须补充的关键项；用户要求直接写时，基于已知信息作保守假设。
- 简单材料可一次生成；复杂材料先生成提纲或要点，确认后分部分扩写。
- 生成后按事实依据、结构完整、语言风格、可执行性和风险边界逐项检查。
- 数据必须可溯源：涉及本地数据（GDP/财政/收入等）走 qiushi-db 地方底座检索，不得臆造。

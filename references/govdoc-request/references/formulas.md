# 请示写作公式库

## 通用公式

### 公式1：标准请示

```
标题：关于+事由+的请示

主送机关：

一、请示原因
（说明为什么要请示，背景、依据、必要性）

二、请示事项
（具体请示什么，内容明确、具体、可操作）

三、结语
妥否，请批示。

发文机关
年 月 日
```

### 公式2：请求批准类请示

```
标题：关于请求批准+事项+的请示

主送机关：

根据+依据/背景，我单位+现状/需求。为+目的，现请求批准+事项。

妥否，请批示。

附件：1. 相关材料
      2. 经费预算

发文机关
年 月 日
```

### 公式3：请求指示类请示

```
标题：关于+问题+的请示

主送机关：

在+工作/过程中，遇到+问题/情况。根据+规定/精神，我单位拟+方案，但+疑问/不明确之处。

特此请示，请予指示。

发文机关
年 月 日
```

## 分类公式

### 1. 请求批准项目

```
标题：关于请求批准+项目名称+的请示

主送机关：

一、项目背景
（说明项目必要性、意义）

二、项目内容
（说明项目规模、内容、周期）

三、经费预算
（说明经费来源、金额、使用计划）

四、请示事项
（明确请求批准的内容）

妥否，请批示。

附件：1. 项目可行性报告
      2. 经费预算明细

发文机关
年 月 日
```

二、资金来源
（说明已筹措资金、缺口资金）

三、请示事项

妥否，请批示。

附件：1. 资金使用计划
      2. 相关依据文件

发文机关
年 月 日
```

### 4. 请求变更事项

```
标题：关于请求变更+事项+的请示

主送机关：

根据+原批准/规定，我单位+原事项。因+原因/情况变化，现请求变更如下：

一、变更原因

（说明原事项、变更后事项）

年 月 日

## 语言模板

### 开头模板
- 为贯彻落实+精神/文件，根据+规定/要求，我单位+行动。
- 根据+文件/会议/领导批示精神，我单位+工作。
- 近年来，+背景/形势。为+目的，我单位+举措。
- 关于+问题，我单位+请示。

### 事项模板
- 现请示如下：
- 特此请示如下：
- 请示事项如下：
- 现将有关事项请示如下：

### 结尾模板
- 妥否，请批示。
- 当否，请批示。
- 可否，请批示。
- 以上请示，请予审批。
- 特此请示，请予批复。
- 以上意见如无不妥，请批转各地各部门执行。

## 注意事项

### 一文一事
- 一份请示只请示一件事
- 多件事应分多份请示
- 避免一文多事

### 不越级请示
- 一般不得越级请示
- 特殊情况需抄送越过的上级机关
- 不直接向更高级机关请示

### 不多头主送
- 一般只主送一个上级机关
- 需要同时送其他机关用抄送形式
- 不主送领导者个人

### 不抄送下级
- 请示不得抄送下级机关
- 批复后可向下级转发
- 保密要求需遵守

## 常见问题

### Q1：请示和报告有什么区别？
- **请示**：需要上级批准，一文一事，事前行文
- **报告**：不需要上级批准，可一文多事，事后行文

### Q2：请示的主送机关如何确定？
- 一般主送直接上级机关
- 受双重领导的机关可同时主送两个上级
- 不得主送领导者个人

### Q3：请示的结尾用语有哪些？
- 妥否，请批示
- 当否，请批示
- 可否，请批示
- 以上请示，请予审批
- 特此请示，请予批复

### Q4：请示需要哪些附件？
- 相关依据文件
- 经费预算明细
- 项目可行性报告
- 干部任免审批表（如适用）
- 其他支撑材料

## 提示词骨架

```text
你是【单位】负责行文的工作人员，擅长请示与批复写作。请按照【请示/批复写作公式】，结合【请示事项与理由】，撰写一份【文种】。要求：一文一事、理由充分可核、请求明确、不夹带其他事项；批复须先引述来文标题与发文字号再表态，字数为【】。
```

## 分步策略

- 信息不足时，先列出必须补充的关键项（请示事项、理由与依据、请求批准的具体内容、时限要求）；用户要求直接写时，对不全项以【待补】占位并显式提示。
- 先判定「是否需要请示」：属本机关职权范围内可自行决定的事项不写请示。
- 请示坚持**一文一事**，不夹带其他事项；报告不得夹送请示。
- 批复须在开头引述来文标题与发文字号再表态；「原则同意」必须附明确条件。
- 生成后按一文一事、理由可核、请求明确、不越级不夹带、批复依据完整逐项检查。

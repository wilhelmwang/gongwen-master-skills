# 批复写作公式库

## 通用公式

### 公式1：标准批复

```
标题：关于+事由+的批复

主送机关：

你单位《关于+请示事项+的请示》（文号）收悉。经研究，现批复如下：

一、批复意见
（同意/不同意/部分同意，请示事项）

二、具体要求
（如何执行、注意事项）

此复。

发文机关
年 月 日
```

### 公式2：审批类批复

```
标题：关于同意+事项+的批复

主送机关：

你单位《关于请求+事项+的请示》（文号）收悉。根据+依据/规定，经研究，同意+事项。具体要求如下：

一、同意内容
（明确同意的具体内容）

二、执行要求
（如何执行、时间要求、质量要求）

三、其他事项
（需要注意的问题）

请按此批复认真贯彻执行。

发文机关
年 月 日
```

### 公式3：指示类批复

```
标题：关于+问题+的批复

主送机关：

你单位《关于+问题+的请示》（文号）收悉。经研究，现批复如下：

一、关于+问题1+
（指示意见）

二、关于+问题2+
（指示意见）

三、关于+问题3+
（指示意见）

请根据上述意见，认真做好相关工作。

发文机关
年 月 日
```

## 分类公式

### 1. 审批项目批复

```
标题：关于同意+项目名称+立项的批复

主送机关：

你单位《关于请求批准+项目名称+立项的请示》（文号）收悉。根据+依据，经研究，同意该项目立项。现将有关事项批复如下：

一、项目内容
（明确项目内容、规模）

二、投资概算
（明确投资金额、资金来源）

三、建设周期
（明确建设时间、里程碑）

四、有关要求
（执行要求、管理要求）

请按此批复抓紧组织实施。

发文机关
年 月 日
```

## 语言模板

### 开头模板
- 你单位《关于+请示事项+的请示》（文号）收悉。
- 《关于+请示事项+的请示》（文号）收悉。
- 收到你单位+日期+报送的《关于+请示事项+的请示》（文号）。

### 意见模板
- 经研究，同意+事项。
- 经研究，不同意+事项。
- 经研究，部分同意+事项。
- 根据+依据，同意+事项。

### 结尾模板
- 此复。
- 特此批复。
- 以上批复，请遵照执行。
- 请按批复要求认真贯彻执行。
- 请根据上述意见，调整相关方案。

## 注意事项

### 有请示才有批复
- 批复必须针对请示
- 无请示不批复
- 批复要一一批复

### 批复意见必须明确
- 同意、不同意、部分同意要明确
- 不能模棱两可
- 要有具体执行要求

### 批复要及时
- 收到请示后及时批复
- 一般不超过规定时限
- 特殊情况需说明

### 批复要一一批复
- 一份批复对应一份请示
- 不要一份批复对应多份请示
- 多份请示应分别批复

## 常见问题

### Q1：批复和请示有什么关系？
- **批复**：上级机关答复下级机关请示
- **请示**：下级机关请求上级机关批准
- 有请示才有批复，批复针对请示

### Q2：批复的主送机关如何确定？
- 主送请示机关
- 受双重领导的机关可同时主送两个上级
- 不主送领导者个人

### Q3：批复的结尾用语有哪些？
- 此复
- 特此批复
- 以上批复，请遵照执行
- 请按批复要求认真贯彻执行

### Q4：不同意请示如何批复？
- 说明不同意的原因
- 提供建议或替代方案
- 语气要委婉、得当

- [ ] 标题是否为"发文机关+事由+批复"

- [ ] 主送机关是否正确
- [ ] 正文结构是否完整
- [ ] 结尾用语是否规范
- [ ] 落款日期是否正确

- [ ] 批复意见是否明确

- [ ] 执行要求是否具体

- [ ] 用词是否准确

# 政务文风集（govdoc-styles · v6.9.0，前身为 biganzi 文风六合一）

> **兼容层**：本模块曾名 biganzi（文风），历史文档/对话中的「biganzi」「文风N」触发词全部有效，由 master 路由别名承接。

> 六种文风 + 会诊模式的统一入口。选择风格 → 加载对应 rules → 写作。
> 完整方法论存于 `references/biganzi-N/SKILL.md`（渐进式披露：本文件只放路由与核心规则摘要，细节按需加载）。

> **触发兼容（历史）**：曾用名「笔杆子1~6 / 大笔杆子N」仍可触发对应文风（文风一~文风六），由路由别名承接；现行术语统一为「文风」。

## 特殊能力（会诊模式）

触发「会诊 / 三笔会诊 / 五笔会诊 / 多风格联审」：默认让文风 1/2/3 围绕同一材料分别给出意见（结构/逻辑/文风/数据），再综合输出；可加文风四（格式合规）、文风五（政治安全）扩至五席。完整流程见 `references/biganzi-roundtable/SKILL.md`。

## 使用流程

```
Step 1 路由：按触发词/上下文选风格（拿不准时问用户一句，或按最接近场景路由）
Step 2 加载：读取 references/对应风格/SKILL.md 的完整规则
Step 3 写作：按该风格的模型/启发式/表达 DNA 输出
Step 4 交付：附「公文大师下一步建议」
```

## 关键规则（各风格通用）

- 诚实边界：风格是"学习其文风"，不冒充具体人物本人（文中不虚构其言论）
- 先补事实，再上风格：数据/背景不足时先追问或说明，不瞎编
- 风格差异优先体现在：结构习惯、句式密度、论证取材、部署语言——保持原文风 DNA

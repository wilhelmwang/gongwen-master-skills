# 02-conversations: 采访与即兴回答

调研时间：2026-06-02

## 来源范围

本地语料中的采访实录部分，重点包括：

- `接受《山西晚报》专访：市长工作应写在大地上`
- `接受《凤凰卫视》专访：耿彦波“围城”`
- `接受《中国青年报》专访：没有文化遗存的城市苍白无力`
- `接受凤凰网《谋城论道》栏目采访：大同，一座城市的争议与荣光`
- `接受《环境保护》杂志专访：走转型路 建生态城`

## 回答模式

1. 先把具体问题抬升到城市战略层。
   - 被问“大同模式”时，不急着夸政绩，而是解释“一轴双城、分开发展”的古城保护模式。
   - 被问产业污染时，先承认重点产业布局，再划出底线：有污染的项目即使能带来收益也不要。

2. 用自己的责任位置回答争议。
   - 被问约谈、问责时，不把责任外推，先承认市长要承担压力，再解释事实结构。
   - 被问“争议人物”时，承认“不情愿”“不是滋味”，但把核心归结为认定后坚持往下走。

3. 喜欢把抽象价值落实到现场动作。
   - “市长工作应写在大地上”不是比喻装饰，而是现场工作法：去一线看规划、发现矛盾、解决矛盾。
   - 对干部作风的要求常落到会议、项目、文件、工地、时限、责任人。

4. 处理压力时使用“选择题”框架。
   - 挨一时骂还是挨千秋骂。
   - 留遗产还是留遗憾。
   - 做官还是做事。
   - 消费人生还是创造人生。

## 即兴表达特征

- 喜欢直接下判断，但通常会补一层历史或制度理由。
- 对理念性问题，先给命题，再展开“为什么”，最后落到工作抓手。
- 对争议不完全回避，会把争议当作提醒、忠告和承压测试。
- 对时间有强烈稀缺感，常用“人生苦短”“舞台有限”“忙就是营养”等表达组织个人动机。

## 可用于 Skill 的对话规则

- 回答用户问题时，先判断这是“战略方向”“材料谋篇”“具体项目”“作风执行”中的哪一类。
- 对战略方向：先找历史坐标、文化坐标、产业坐标。
- 对材料谋篇：用“命题-问题-逻辑-路径-作风”展开。
- 对具体项目：追问或搜索事实，特别是规划、资金、民生、生态、程序风险。
- 对争议问题：承认代价和张力，不把复杂问题写成单向赞歌。

# 06-timeline: 人物时间线

## 时间线

| 时间 | 事件 | 对思维框架的影响 |
| --- | --- | --- |
| 1958-11 | 生于山西和顺 | 山西地方历史文化成为其城市叙事的重要底色 |
| 1976-08 | 参加工作 | 基层经历使其讲话常带现场感和干部动员气 |
| 1981-12 | 加入中国共产党 | 形成典型地方党政干部表达体系 |
| 1995-2000 | 任灵石县委副书记、县长等职 | 王家大院等文化资源保护开发经验成型 |
| 2000-2004 | 任榆次市委书记、晋中市委常委/榆次区委书记 | 常家庄园、老城保护与城市化思路进一步成型 |
| 2004-2006 | 任山西省政府副秘书长兼省政府机关事务管理局局长等 | 从地方项目治理进入省级机关视角 |
| 2006-2008 | 任太原市副市长等职 | 城建、规划、城市管理经验继续积累 |
| 2008-2013 | 任大同市委副书记、市长 | “一轴双城”、大同古城保护、资源型城市转型成为其最集中案例 |
| 2013-2019 | 任太原市委副书记、市长 | 将城建、道路、生态、水利、城市更新方法带入省会治理 |
| 2017 | 科技部调研太原可持续发展议程创新示范区申报，公开报道显示其以太原市委副书记、市长身份参加 | 说明其太原阶段也围绕资源型城市可持续发展和生态修复展开 |
| 2019 | 卸任太原市市长，后公开资料显示任山西省政府参事 | 从一线行政主官转入参事身份 |
| 2024-12 | 公开报道显示以山西省名人联合会代理会长身份亮相 | 退休后仍与地方文化、社会组织活动有关 |

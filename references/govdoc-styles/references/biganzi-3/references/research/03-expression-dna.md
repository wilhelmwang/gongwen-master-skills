# 03 表达 DNA

## 统计观察

来自 `00-corpus-stats.md`：

- 正文高频主题：产业、创新、改革、落实、项目、人民、安全、开放、生态、高质量发展、现代化、统筹、治理、风险、制造业。
- 标题高频：宁波、高质量发展、改革、安徽、攻坚、开放、创新、产业、现代化、人才。
- 结构标记高频：必须、要坚持、第一、当前、一是、二是、三是、要强化、要加快、要推动。

## 句式偏好

### 1. 大判断开篇，分层推进

常见写法：

- “这是……的重要一年/关键时期/重大任务。”
- “做好这项工作，意义重大、责任重大。”
- “总的要求是……”
- “重点抓好以下几方面工作。”

然后进入“一是、二是、三是”或“第一、第二、第三”。

### 2. 动宾短语密集，行动感强

高频动作：

- 拉高标杆、扬长补短、抢抓机遇、攻坚突破、精准发力、统筹推进、强化保障、跟踪问效。
- 把优势做强、把短板补齐、把风险守住、把责任压实、把任务落细。

### 3. 喜欢成组概括

常见组合：

- 改革强市、创新强市、开放强市、人才强市。
- 项目争速、产业争先、科技争投、城乡争优、服务争效、党建争强。
- 心中有数、心中有秤、心中有底。
- 项目化、清单式、责任制。
- 政治建设、高质量发展、改革开放、全面从严治党等“答卷”式表达。

### 4. 数字和工程名承担说服功能

他常用规划指标、工程名、平台名、行动名、产业集群名称让材料显得可执行。如“225”“246”“3433”“六争攻坚”“最多跑一次”“单项冠军之城”等。

## 叙述节奏

1. 先讲政治/战略方位。
2. 再讲现实基础与问题短板。
3. 然后提出目标定位和对标要求。
4. 接着展开工作抓手。
5. 最后压到责任、作风、督查、考核。

## 价值词与禁忌词

高价值词：

- 高质量、实体经济、创新、改革、开放、项目、产业链、市场主体、人民、落实、安全、统筹、标杆、攻坚、实效。

慎用或少用：

- 过度抒情、个人化、文学化铺陈。
- 没有抓手的“赋能、矩阵、生态、闭环”等泛词。
- 只有口号没有项目、机制、主体、时限、考核的表达。

## 标题 DNA

常见标题公式：

1. “动词 + 关键任务 + 目标结果”：加快建设……、推动……、奋力谱写……
2. “双动词/三动词排比”：拉高标杆创一流、扬长补短创优势。
3. “战略命题 + 行动落点”：牢牢把握高质量发展这个首要任务。
4. “学习贯彻 + 奋力/扎实 + 具体事业”：深入学习贯彻……奋力谱写……

## 写作禁区

- 不能只仿排比，忽略问题和抓手。
- 不能把所有材料都写成“热烈号召”，要保留问题意识和硬任务。
- 不能用“个人口吻”模拟郑栅洁本人，必须保持公开材料的制度化表达。

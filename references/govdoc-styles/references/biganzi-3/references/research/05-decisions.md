# 05 决策记录与行动模式

## 代表性公共行动主题

### 1. 充电基础设施：把新产业推广瓶颈转成基础设施和标准体系

材料包括国务院政策吹风会、充电基础设施三点建议、推动充电设施基础建设六大重点任务。

行动模式：

- 识别短板：充电设施滞后制约新能源汽车推广。
- 明确目标：形成车桩相随、智能高效的基础设施体系。
- 拆解抓手：规划、建设、标准、市场、审批、财政、用地、部门责任。
- 建立协同：地方主体责任、部门分工、企业参与、联盟平台。

### 2. 宁波“六争攻坚”：把城市发展目标转为竞进式行动体系

主题包括项目争速、产业争先、科技争投、城乡争优、服务争效、党建争强。

行动模式：

- 用“争”字激发比学赶超。
- 用“攻坚”处理难点瓶颈。
- 用项目、产业、科技、城乡、服务、党建覆盖经济社会关键面。
- 用督查、考核、责任压实保证落实。

### 3. “最多跑一次”：把改革牵引到政务流程和制度供给

行动模式：

- 从群众和企业办事感受出发。
- 把审批、数据、标准、服务、监管联动起来。
- 追求可衡量的时间、次数、材料、流程压减。
- 把改革经验转成长期制度安排。

### 4. 制造业和产业链：从单个企业扶持转向链群生态

材料包括“246”产业集群、制造业单项冠军之城、产业链安全等。

行动模式：

- 以实体经济为根。
- 以龙头企业、单项冠军、专精特新、上下游协同为主体。
- 以创新、人才、金融、土地、平台为要素。
- 以产业链韧性和安全作为疫情后重要判断维度。

### 5. 安徽高质量发展：把区域定位嵌入长三角和国家现代化布局

行动模式：

- 用长三角一体化找区域坐标。
- 用科技创新、制造业、改革开放、乡村振兴、民生和党建组成发展框架。
- 以“稳字当头、稳中求进”处理增长、民生、风险和安全。

### 6. 国家发改委时期：从地方治理转向宏观协调和国家战略施工图

材料包括宏观调控、高质量发展、现代化产业体系、中国式现代化、粮食安全、“一带一路”等。

行动模式：

- 更强调规划实施、宏观政策、产业体系、国家安全、国内国际双循环。
- 仍保持“战略转施工图”的写法：目标、任务、重大举措、项目支撑、政策协同、落实机制。

## 决策启发式

1. 遇到新产业，先找基础设施和标准短板。
2. 遇到地方发展，先找国家战略坐标，再找自身优势。
3. 遇到改革任务，先找企业和群众感受最强的堵点。
4. 遇到产业问题，先看链条、集群、龙头、平台、人才和金融。
5. 遇到风险冲击，先稳基本盘，再从危机中捕捉结构升级机会。
6. 遇到宏观任务，必须拆成施工图：任务、项目、主体、时限、考核。

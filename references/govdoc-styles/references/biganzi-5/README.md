# biganzi-5 模块说明

> 本文件为子模块索引（统一规范 M1 最小文件集：SKILL.md + LICENSE + README.md）。

## 这是什么
文风五：基层工作风格模型。专注于乡镇/街道/社区工作汇报、总结、经验材料、典型发言。   适用于用户说"文风五""基层风格""乡镇汇报""社区总结""村居经验材料""基层工作者视角"等场景。   语料双轨：①快速轨——用户提供 3-5 篇本单位/同类基层范文即可立即蒸馏出精准风格（role-distill 流程）；

## 语料与口径
- 完整方法论：`SKILL.md`（角色/模型/规则/示例）
- 研究档案：`references/research/`（01 文章 → 07 质检档案，biganzi 族专有）
- 原始语料：`references/sources/articles/`（文本/文档，仅供风格模仿学习）

## 使用
由 `../SKILL.md`（biganzi 入口）路由表定位后，按其指示加载本模块规则即可。

## 边界
- 只学习行文方法与表达风格，不冒充具体人物本人；不虚构其言论。
- 语料版权归原作者/刊物，仅供内部学习。

# 文风六 · 央企/国企风格模型

> v1.1.0 骨架蒸馏 → v1.2.0 补厚核心心智模型 → v1.4 对齐 b1-b3 结构（方法论就绪，语料蒸馏待扩采）。专注央企国企年报、领导讲话、战略材料。

## 风格定位

| 维度 | 特征 |
|---|---|
| 语言风格 | 正式、宏观、战略导向，政治站位高、经营话语熟 |
| 逻辑结构 | 战略定位→业务布局→核心能力→风险管控→未来展望 |
| 适用文种 | 年度工作报告、领导讲话、战略规划、董事会报告、专题汇报 |
| 句式偏好 | 长句、复合句为主，善用"坚持…推动…实现…"递进链 |

## 核心心智模型

### 模型1：政治站位模型
央企材料必有政治开场（"深入学习贯彻二十大精神""胸怀'国之大者'"），把经营讲成政治担当。

### 模型2：战略航向模型
先讲"方位"（行业趋势/国家需求/集团使命），再定"航向"（战略目标），经营举措是战略的展开。

### 模型3：主业聚焦模型
"聚焦主责主业"是央企铁律——突出核心业务、压减非主业，用"主业占比 XX%"数据立论。

### 模型4：三个责任模型
政治责任+经济责任+社会责任三位一体，体现央企担当（保供稳价、科技创新、乡村振兴）。

### 模型5：对标赶超模型
"对标世界一流"，找差距（与行业标杆比指标）、定路径（对标清单+专项行动）。

### 模型6：风险合规模型
经营中必有风险防控段（安全/资金/廉洁），"守住不发生系统性风险底线"是标配结语。

## 决策启发式

- 用户要"年度工作报告"→ 模型1+2+6（政治+战略+风险）
- 用户要"战略规划"→ 模型2+5（战略+对标）
- 用户要"领导讲话"→ 模型1+3（政治+主业）
- 用户要"专题汇报"→ 模型4（三个责任，突出担当）

## 表达 DNA

### 篇章骨架
- 开头：政治站位 + 年度总况（"过去一年，集团坚持以…为统领，实现…"）
- 主体：四到五块（党建引领/经营发展/改革创新/风险防控）
- 结尾：展望号召（"奋力开创…新局面"）

### 句式偏好
- 递进链："坚持政治引领，铸牢忠诚之魂；坚持战略聚焦，壮大主业之基…"
- 数字段式："全年实现营收 X 亿元，同比增长 X%；利润总额 X 亿元…"
- 对标式："较上年提升 X 个位次""跑赢行业大盘"

### 高频词
国之大者、主责主业、高质量发展、改革深化提升行动、世界一流企业、科技创新、绿色低碳、安全发展

## 谋篇模板

### 模板A：年度工作报告（标准型）
```
标题：XX集团2026年度工作报告
一、2026年工作回顾
（1. 党建引领 2. 经营指标 3. 重点任务完成）
二、形势研判
三、2027年工作部署
（总体要求 + 五项重点任务 + 保障措施）
```

### 模板B：战略规划（蓝图型）
```
标题：XX集团"十五五"发展规划
一、发展基础与环境
二、总体思路与目标（1+2+3 指标体系）

```

```
一、充分肯定成绩，坚定发展信心

三、突出工作重点，抓好关键环节
四、坚持党建引领，凝聚奋斗力量
```

## 核心心智模型（v1.4 补厚 · 对齐 b1-b3 结构）

### 模型一：三率记分牌
经营汇报的骨架：**紧盯三个率**（如资产负债率/研发投入强度/考核覆盖率），每个率给「变化值+历史对照」（下降 3.2 个百分点，守住警戒线/提高到 3.5%，创历史新高）。三个率即本年记分牌。

### 模型二：对标世界一流句式
「对标 XX 行动开展以来，聚焦三个环节：采购环节……生产环节……投资环节……」——每环节「指标+变化+金额」三件套，禁止只讲举措不讲数。

### 模型三：责任传导收尾
经营语言收尾必须落考核：「把对标指标纳入负责人年度考核，对标不达标、考核不过关」——国企口径的特点是**成绩背后必挂机制**，数据讲完落到人的责任。

### 模型四：主业聚焦表述
「非主业投资压减 40%，资源向主业集中」——国资监管语境下，压减与集中是同一件事的两面。涉及多元化经营的表述，先讲压减再讲集中，站位即正。

### 模型五：改革话语规范
「改革深化提升行动」「能上能下」「防风险守底线」等提法遵循国资委现行口径；「记分牌」「指挥棒」等比喻可用，但每段限一个。

### 模型六：诚实地带
- 经营业绩数据以审计口径为准，宣传口径不得高于审计口径；
- 涉及未披露经营信息，遵循上市规则/国资信披要求，不虚构不预判。

## 黄金样本（few-shot · 方法论构造样本 + 风格拆解）

> 本风格原始语料未随包分发，以下为按「央企国企经营口径」语体特征构造的示范段。

### 样本一：经营汇报（对标世界一流 + 经营数据 + 管理动作）
**示范段**：「对标世界一流管理提升行动开展以来，我们聚焦三个环节：采购环节，集中采购率由 78% 提升到 92%，年度节约成本 3,600 万元；生产环节，全员劳动生产率同比提高 11%；投资环节，非主业投资压减 40%，资源向主业集中。下一步，把对标指标纳入各单位负责人年度考核，『对标不达标、考核不过关』。」
**风格拆解**：①「聚焦三个环节」清单式结构；②每环节「指标变化+金额/百分比」硬数据；③收尾落到考核机制（对标不达标、考核不过关）——国企口径的责任传导。
**仿写演示**（同一内容·国企改革深化）：「改革深化提升行动中，我们紧盯三个率：资产负债率下降 3.2 个百分点，守住警戒线；研发投入强度提高到 3.5%，创历史新高；全员绩效考核覆盖率 100%，干部能上能下调整 17 人。三个率，就是今年改革的记分牌。」

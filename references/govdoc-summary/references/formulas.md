# 总结汇报写作公式

## 工作总结

工作总结篇章=帽段+主体段（做法）+主体段（问题）+主体段（计划）
帽段=指导思想句+情况背景句+工作思路句+工作成果句
主体段（做法）=主题句（Why）+支撑句（How）+支撑句（What）
主体段（问题）=客观形势句+问题表现句
主体段（计划）=形势分析句+工作思路句+结尾句

## 工作汇报

工作汇报篇章=标题+引言段+主要情况部分+存在的问题部分+有关建议部分
标题=关于【报告事项概括】+汇报
引言段=指导思想句+情况背景句+工作思路句+总体成效+过渡句
主要情况部分=汇报事项段1+汇报事项段2+汇报事项段3……

## 提示词骨架

```text
你是【单位】办公室主任，熟悉【工作领域】。请按照【总结/汇报写作公式】，结合【素材/提纲】撰写【工作总结/工作汇报】。要求数据支撑充分、定性与定量结合、语言简洁专业，字数为【】。
```

## 分步策略

- 素材多：先归类为“理论依据、工作方法、具体事项、结果数据”。
- 总结长稿：先生成做法段，再生成帽段、问题段、计划段。
- 汇报材料：先生成提纲并确认，再逐部分扩写。

# 理论文章写作公式

## 选题方法

理论文章选题=最新指示精神+近期宣传重点+本地特色实践

操作：
1. 从重要讲话、权威文章、政策文件中找理论依据。
2. 从目标媒体近期文章中找宣传重点和表达偏好。
3. 与本地特色、单位实践取交集，确定小切口选题。

## 观点架构

理论文章观点=核心观点+3-4个分论点
分论点要求=方向明确+逻辑递进+能被事实或政策论证

## 成文结构

理论文章篇章=标题+开篇段+分论点段1+分论点段2+分论点段3+结尾段
开篇段=政策背景+现实意义+核心观点
分论点段=观点句+理论依据+实践支撑+意义提升
结尾段=总结观点+行动指向

## 提示词骨架

```text
你是【目标媒体】理论版资深编辑，熟悉理论文章写作风格。请根据【政策材料/宣传重点/本地实践】，为我列出【领域】理论文章选题。要求切口小，说明与政策和实践的关系。
```

```text
请围绕【选题】，列出一篇理论文章的核心观点和3-4个分论点。要求观点有新意，逻辑递进，能够结合【本地实践】论证。
```

```text
请按照【目标文风】和【观点框架】撰写一篇理论文章。要求权威严谨、虚实结合、语言符合报纸理论文章风格，字数为【】。
```
## 分步策略

- 信息不足时，先列出必须补充的关键项；用户要求直接写时，基于已知信息作保守假设。
- 简单材料可一次生成；复杂材料先生成提纲或要点，确认后分部分扩写。
- 生成后按事实依据、结构完整、语言风格、可执行性和风险边界逐项检查。

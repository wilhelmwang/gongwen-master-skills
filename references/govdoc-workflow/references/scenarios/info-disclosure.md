# 政府信息公开申请答复流程场景卡（info-disclosure）

> 依据：《政府信息公开条例》（2019 修订）+ 各地办理口径（详见 regulations.md）。
> 适用：行政机关办理公民/法人/其他组织的政府信息公开申请。
> 时限铁律：**收到之日起 20 个工作日内答复；延长 ≤20 个工作日（须书面告知理由）。**

## 流程总览（4 节点）

```
[节点1] 登记受理 → [节点2] 补正/征询 → [节点3] 答复 → [节点4] 救济告知
```

## 节点明细

### 节点 1：登记受理（找谁：本机关公开办/办公室）

| 项 | 内容 |
|---|---|
| **登记** | 申请书/申请人信息/信息描述/获取方式 |
| 要点 | 合法申请三要件：申请人信息完整 + 描述明确可检索 + 获取方式明确；信访咨询/电话询问**不产生 20 日法定答复义务**（须甄别转性） |

### 节点 2：补正/征询（找谁：申请人 + 第三方）

| 项 | 内容 |
|---|---|
| **公文①** | **补正告知（函）**——7 个工作日内一次性告知补正（不得反复要求） |
| **公文②** | **第三方意见征询函（govdoc-letter）**——涉商业秘密/个人隐私的征询第三方意见 |
| 要点 | 描述不明确的可要求补正；涉第三方权益的公开前征询（第三方逾期未意见不必然公开，综合判断） |

### 节点 3：答复（找谁：申请人）

| 项 | 内容 |
|---|---|
| **公文③** | **政府信息公开答复书（govdoc-letter 法定格式）** |
| 答复类型 | ①予以公开（含提供获取方式）②不予公开（写明法定豁免理由）③部分公开（区分处理）④不属于本机关公开范围（告知理由与途径）⑤信息不存在（尽检索义务后）⑥逾期未补正视为放弃 |
| 要点 | 延长答复须书面告知理由且 ≤20 个工作日；**无法定豁免（国家秘密/商业秘密隐私/内部事务/过程信息）原则上一律公开**；多申请人相同信息可纳主动公开 |

### 节点 4：救济告知（找谁：行政复议机关/法院）

| 项 | 内容 |
|---|---|
| 要点 | 答复书须告知救济途径：60 日内可申请行政复议 / 6 个月内可提起行政诉讼 |
| 关联场景 | 被申请复议/应诉 → 转用 `reconsideration.md` 场景卡 |

## 地方本地参数

- 公开办：各单位办公室（政府信息公开工作机构）；复议机关：地方人民政府（司法局承办）
- 起草引用法规：《中华人民共和国政府信息公开条例》（国务院令第 711 号）

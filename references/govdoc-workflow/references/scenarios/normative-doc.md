# 规范性文件制定发布流程场景卡（normative-doc）

> 依据：《海南省行政规范性文件制定与备案规定》（司法部刊载 2025-12）+ 通化/漯河/台州/常州新北等地 2025-2026 指引（详见 regulations.md）。
> 适用：行政机关制定涉及公民/法人权利义务、具有普遍约束力、反复适用的公文（办法/规定/细则等）。
> 程序铁律：**未经合法性审核不得提交集体审议；未经公布不得作为行政管理依据。**

## 流程总览（6 节点）

```
[节点1] 立项 → [节点2] 起草与评估论证 → [节点3] 征求意见 → [节点4] 合法性审核
→ [节点5] 集体审议决定 → [节点6] 公布/备案/施行
```

## 节点明细

### 节点 1：立项（找谁：本级政府/办公机构）

| 项 | 内容 |
|---|---|
| **公文①** | **制定立项申请（请示）**——列入政府发文计划 |
| 要点 | 上位法/上级文件已有明确规定的不得重复制定；议事协调机构/内设机构不得制定 |

### 节点 2：起草与评估论证

| 项 | 内容 |
|---|---|
| **公文②** | **送审稿 + 起草说明**（govdoc-plan 条文体）——必要性/可行性/预期效果与影响评估结论须写入起草说明 |
| 要点 | 跨部门职权的联合起草（一个部门为主）；专业性强的组织专家论证；名称规范（办法/规定/细则用条文式，以"通知"文种印发） |

### 节点 3：征求意见（找谁：相关单位 + 社会公众）

| 项 | 内容 |
|---|---|
| **公文③** | **征求意见函（govdoc-letter）**——书面征求相关单位 |
| **公文④** | **公开征求意见公告（govdoc-notice）**——网站/报刊公开 |
| 要点 | 公开期限：一般 ≥10-15 个工作日，涉市场主体 ≥30 日；意见采纳/不采纳情况写入起草说明；涉企业重大利益的听取行业协会商会 |

### 节点 4：合法性审核（找谁：司法局/本部门审核机构）

| 项 | 内容 |
|---|---|
| **公文⑤** | **合法性审核申请（函）**——附送审稿/起草说明/依据对照表/征求意见采纳情况/专项评估（公平竞争/风险/性别平等）/集体审议材料 |
| 要点 | 审核时限 5-15 个工作日；**不得以征求意见/会签/法律顾问意见代替合法性审核**；未经审核不合法的不得提请审议 |

### 节点 5：集体审议决定（找谁：政府常务会/部门办公会）

| 项 | 内容 |
|---|---|
| **公文⑥** | **提请审议请示（govdoc-request）**——政府文件由起草部门集体讨论通过后提请 |
| 要点 | 未采纳合法性审核意见的须详细说明理由；紧急情形（突发事件等）经主要负责人批准可简化程序，但合法性审核+集体审议不可免 |

### 节点 6：公布/备案/施行

| 项 | 内容 |
|---|---|
| **公文⑦** | **印发通知（govdoc-notice）**——统一登记/编号（文种代字"规"）/公布；主要负责人签发 |
| **公文⑧** | **备案报告（govdoc-report）**——公布之日起 15 日内报上级行政机关（径送司法行政部门），附正式文本/起草说明/对照表/审核意见 |
| 要点 | 施行日期：公布之日起 30 日后（涉市场主体留 ≥60 日适应期；授益性/紧急的可即日）；"暂行/试行"须载明有效期（≤3 年）；明确同时废止的文件 |

## 禁设事项（起草红线）

不得设定：行政许可/行政处罚/行政强制；不得增加法定外权力、减损法定职责；不得违法减损公民法人权利或增设义务；不得排除限制公平竞争。

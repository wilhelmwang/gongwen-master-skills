# 干部选拔任用流程场景卡（personnel）

> 依据：《党政领导干部选拔任用工作条例》（2019 修订）+ 各地单位实施方案（无锡审计局/遂昌/惠州人大机关等，详见 regulations.md）。
> 适用：党委（党组）管理权限内干部的动议到任免全过程。
> ⚠️ 红线：本卡只梳理**程序与文书**，不涉及任何具体人选评价。

## 流程总览（6 节点）

```
[节点1] 动议 → [节点2] 民主推荐 → [节点3] 考察 → [节点4] 讨论决定
→ [节点5] 报批/备案 + 任前公示 → [节点6] 任职发文与归档
```

## 节点明细

### 节点 1：动议（找谁：本单位党组 + 组织部门）

| 项 | 内容 |
|---|---|
| **公文①** | **干部选拔任用工作方案（方案类）**——职位/条件/范围/方式/程序/人选意向 |
| 要点 | 主要领导成员酝酿；岗位空缺与队伍分析；方案经党组同意后启动 |

### 节点 2：民主推荐（找谁：本单位）

| 项 | 内容 |
|---|---|
| **公文②** | **民主推荐通知**（govdoc-notice）——会议推荐+谈话调研推荐 |
| **公文③** | **推荐情况报告（报告）**——推荐结果汇总 |
| 要点 | 参加推荐人数≥应参加人数 2/3；推荐结果作为选拔重要参考（非票决） |

### 节点 3：考察（找谁：考察组 + 纪检/信访/档案联审）

| 项 | 内容 |
|---|---|
| **公文④** | **考察预告**（govdoc-notice 简式） |
| **公文⑤** | **干部考察材料（报告）**——德能勤绩廉 + 具体事例，归档件 |
| 要点 | 必须查核：档案（三龄两历一身份）/廉政意见/信访线索/巡视巡察结论 |

### 节点 4：讨论决定（找谁：党组会）

| 项 | 内容 |
|---|---|
| **公文⑥** | **党组会议纪要（govdoc-minutes）**——逐个介绍/充分讨论/表决（应到会过半数同意） |
| 要点 | 不得提交情形：未推荐未考察/纪检有不同意见/档案存疑/信访未清/巡视问题未结论 |

### 节点 5：报批/备案 + 任前公示（找谁：上级组织部门）

| 项 | 内容 |
|---|---|
| **公文⑦** | **干部任免请示（govdoc-request）**——附任免审批表/考察材料/档案/会议纪要/推荐情况 |
| **公文⑧** | **任前公示（govdoc-notice）**——公示期 ≥5 个工作日；破格提拔须说明情形理由 |
| 要点 | 需报批的（上级审批任职）走请示；需备案的（本级管理）走备案文；公示不影响任职才办手续 |

### 节点 6：任职发文与归档

| 项 | 内容 |
|---|---|
| **公文⑨** | **任职通知（govdoc-duty/notice）**——试用期（一年）标注；发文主体=党组 |
| **公文⑩** | **任职谈话记录**（内部文书） |
| 要点 | 任免审批表+考察材料入本人档案；机构编制实名制系统同步变更 |

## 时限速查

公示 ≥5 工作日 ｜ 试用期 1 年（非选举产生的处级以下）｜ 任职时间自党组决定之日起算

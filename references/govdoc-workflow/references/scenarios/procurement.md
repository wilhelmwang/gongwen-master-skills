# 政府采购流程场景卡（procurement）

> 依据：《政府采购法》+ 各地采购工作指南通行做法（西藏 2025 指南/禹会/晋江等，详见 regulations.md）。
> 适用：预算单位使用财政性资金采购集中采购目录内或限额标准以上的货物/服务/工程。

## 流程总览（5 节点）

```
[节点1] 预算编制 → [节点2] 采购需求与计划 → [节点3] 采购方式报批 → [节点4] 组织采购 → [节点5] 合同/验收/支付
```

## 节点明细

### 节点 1：预算编制（找谁：本单位财务 → 财政局）

| 项 | 内容 |
|---|---|
| 前置 | 年度预算编制窗口；属集中采购目录或达限额标准 |
| **公文①** | **政府采购预算表**（随部门预算报送，表格附件型）|
| 要点 | 品目名称/内容/数量/金额应编尽编；工程项目达限额同样编采购预算 |

### 节点 2：采购需求与计划（找谁：财政局备案）

| 项 | 内容 |
|---|---|
| 前置 | 财政批复预算 |
| **公文②** | **政府采购实施计划备案文（报告）**——项目名称/内容/预算金额/组织形式/采购方式 |
| **公文③** | **采购需求调查报告**（ govdoc-plan 附）——面向公众/市场主体的需求调查（涉新技/重大项） |
| 要点 | 采购意向公开（限额以上项目，采购活动开始前至少 30 日） |

### 节点 3：采购方式报批（找谁：财政局）

| 项 | 内容 |
|---|---|
| **公文④** | **采购方式变更/单一来源申请（请示）**——拟用单一来源/邀请招标等非公开招标方式的论证 |
| 要点 | 公开招标为默认；单一来源须论证唯一性（专有技术/后续扩充/紧急）；进口产品须另行论证审批 |

### 节点 4：组织采购（找谁：集采机构/代理机构）

| 项 | 内容 |
|---|---|
| **公文⑤** | **委托代理协议**（govdoc-letter 合同类）——委托集采机构或社会代理 |
| 要点 | 采购文件/公告/评审/结果公告各环节按限时时限；质疑投诉期 7 个工作日 |

### 节点 5：合同、验收、支付（找谁：供应商 + 本单位财务 + 财政局）

| 项 | 内容 |
|---|---|
| **公文⑥** | **政府采购合同**（法定文本，govdoc-letter）——中标通知书发出 30 日内签订 |
| **公文⑦** | **履约验收报告**（govdoc-report 简式）——按合同逐项验收 |
| **公文⑧** | **资金支付申请**（表格/函）——凭合同+验收单走国库集中支付 |
| 要点 | 合同备案（7 个工作日内）；履约验收不合格的不得支付 |

## 金额档位参考（差异大，须核对本地标准）

- 采购限额：货物/服务常见 30-50 万，工程常见 60-120 万（禹会：货服 30 万/工程 60 万）
- 公开招标数额标准：货物服务常见 200 万+（晋江同），工程 400 万+
- 限额以下：1 万自行采购；1-10 万集体研究直接委托；10 万-限额 多方式可选

## 地方本地参数

- 财政审核/备案：地方财政局；招标投标监督：相关行业主管部门
- 集采机构：地方政府采购中心（以当地现行文件为准）

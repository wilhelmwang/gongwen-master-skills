# 政府投资项目审批流程场景卡（project-approval）

> 依据：《政府投资条例》（国务院令第 712 号）+ 各地政府投资项目管理办法通行做法（详见 regulations.md）。
> 适用：党政机关/事业单位用财政性资金的新建、改建、扩建、技术改造类固定资产投资项目。

## 流程总览（6 节点）

```
[节点1] 部门内部启动 → [节点2] 发改立项（项目建议书）→ [节点3] 发改可研批复
→ [节点4] 数据局技评 + 财政局预算评审 → [节点5] 初设概算批复 → [节点6] 实施与变更
```

## 节点明细

### 节点 1：部门内部启动（找谁：本单位 + 主管部门 + 县/市政府）

| 项 | 内容 |
|---|---|
| 前置 | 明确项目必要性、规模、估算投资；对照本地重大项目决策门槛（常见：500 万以上需政府常务会议决策） |
| **公文①** | **请示**（govdoc-request）——向主管部门/政府请示立项意愿，附初步方案 |
| 要点 | 写清：项目名称、建设内容与规模、投资匡算、资金来源（申请财政资金）、预期效益；声明"已列入/建议列入年度计划" |

### 节点 2：发改立项——项目建议书审批（找谁：发改委）

| 项 | 内容 |
|---|---|
| 前置 | 资金安排意见（财政局出）、建设依据文件 |
| **公文②** | **项目建议书**（govdoc-plan，论证体）——必要性/建设内容规模/拟建地点/投资估算/资金筹措/效益分析 |
| **公文③** | **立项申请文（请示）**——报发改委附项目建议书与附件清单 |
| 要点 | 500 万以下或已列入规划的项目可免项目建议书（直接可研）；引用依据：《政府投资条例》第 X 条 + 本地办法 |

### 节点 3：可研批复（找谁：发改委）

| 项 | 内容 |
|---|---|
| 前置 | 项目建议书批复、用地预审选址（涉新增用地）、社会稳定风险评估（涉公共利益）、节能审查 |
| **公文④** | **可行性研究报告**（govdoc-plan 深度版）——技术经济可行性/资金落实/招标事项核准表 |
| **公文⑤** | **可研报批申请（请示）** |
| 要点 | 可研深度：招标范围/方式/组织形式必须载明；估算不得突破决策审定额度 |

### 节点 4：技评 + 财评（找谁：数据局（信息化部分）→ 财政局）

| 项 | 内容 |
|---|---|
| 前置 | 可研批复、初设方案（信息化项目为初步设计方案） |
| **公文⑥** | **技术评审申请（函/请示）**——报数据局，附建设方案（功能需求/数据共享方案/设备选型/等保定级/密码应用） |
| **公文⑦** | **预算评审申请（函/请示）**——报财政局，附经费测算明细与依据 |
| 要点 | 信息化项目技评重点：存量利用/系统整合/云网资源/数据共享（未按要求共享原则上不通过）；财评重点：财政可承受能力 + 事前绩效评估 |

### 节点 5：初设概算批复（找谁：发改委/行业主管部门）

| 项 | 内容 |
|---|---|
| 前置 | 可研批复、技评意见、财评意见 |
| **公文⑧** | **初步设计（含概算）报批文（请示）** |
| 要点 | 概算不得超可研估算的 10%；超 10% 需重报可研 |

### 节点 6：实施与变更（找谁：原审批部门）

| 项 | 内容 |
|---|---|
| **公文⑨** | **变更/概算调整申请（请示）**——征得行业主管部门同意后报原审批部门 |
| 要点 | 一般变更（≤10% 且预备费可解决）备案；重大变更走原审批程序 |

## 地方本地参数（org_chart 实名，其他城市自行替换）

- 发改节点：地方发展和改革委员会
- 技评节点：地方数据局
- 财评节点：地方财政局
- 并联审批/政务服务：地方政务服务管理局

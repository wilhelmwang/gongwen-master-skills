# 人大建议与政协提案办理流程场景卡（suggestion-reply）

> 依据：各地人大代表建议/政协提案办理工作制度通行做法（怀宁/子洲/延安/宁国等，详见 regulations.md）。
> 适用：承办单位办理人大代表建议、政协提案的全流程（交办→办理→答复→跟踪）。
> 时限铁律：**交办起 3 个月内办结答复**（复杂的经批准可延 1-3 个月，最迟不超 6 个月）。

## 流程总览（5 节点）

```
[节点1] 交办签收 → [节点2] 办理方案 → [节点3] 沟通办理（主办/会办协同）
→ [节点4] 答复函 → [节点5] 满意度与跟踪
```

## 节点明细

### 节点 1：交办签收（找谁：政府办督查科/人大代工委/政协提案委）

| 项 | 内容 |
|---|---|
| 前置 | 两会闭会后联合交办会，承办单位签收清单 |
| **公文①** | **任务调整申请（函）**——不属本单位职责或需调整主办/协办的，收到后 5-7 个工作日内书面说明（逾期视为无异议） |
| 要点 | 不得自行转办；主办/协办由交办机关指定 |

### 节点 2：办理方案（找谁：本单位 + 分管县领导）

| 项 | 内容 |
|---|---|
| **公文②** | **办理工作方案（govdoc-plan）**——重点建议提案须成立办理工作小组 |
| 要点 | 主要领导牵头/分管领导负责/专人办理；确定"三见面"沟通计划 |

### 节点 3：沟通办理（找谁：代表委员 + 会办单位）

| 项 | 内容 |
|---|---|
| **公文③** | **会办意见函（govdoc-letter）**——协办单位签收后 1-2 个月内函告主办单位 |
| 要点 | 主办主动协调；分歧由主办综合；调研/座谈/上门走访留痕 |

### 节点 4：答复函（找谁：代表委员 + 交办机关）

| 项 | 内容 |
|---|---|
| **公文④** | **人大代表建议答复函（govdoc-letter，法定格式）**——承办单位名义、主要领导签发，不得以内设机构名义 |
| **公文⑤** | **政协提案答复函（同上）** |
| 要点 | 逐件办复；办理结果标 **A（已解决）/B（正在解决/列入计划）/C（因条件限制暂不能解决，如实说明）** 三类；随附反馈意见表；应公开的复函上门户网站公开 |

### 节点 5：满意度与跟踪

| 项 | 内容 |
|---|---|
| **公文⑥** | **重新办理答复（函）**——代表/委员不满意的，交办机关责成重办，1-2 个月内再答复 |
| **公文⑦** | **办理工作总结报告（govdoc-report）**——承办 5 件以上的单位报送 |
| 要点 | 目标口径：按时办复率 100%/复函规范率 100%/满意率 95%+ |

## 地方本地参数

- 交办机关：地方人民政府办公室（督查室）
- 人大侧：地方人大常委会（代表工作委员会）；政协侧：政协地方委员会（提案委员会）
- 协办节点单位可经 org_chart 实名引用

# 督查督办事项办理流程场景卡（supervision）

> 依据：各地督查督办工作规则/办法通行做法（兰州信访局/凯里纪委/银川住建"135"/民航飞行学院/岭南师院 2026 修订，详见 regulations.md）。
> 适用：承办单位对上级交办、领导批示、会议议定事项的督办办理全流程。
> 闭环铁律：**台账式统筹、清单式管理、办结销号、件件有落实事事有回音。**

## 流程总览（5 节点）

```
[节点1] 立项登记 → [节点2] 交办分办 → [节点3] 承办办理 → [节点4] 催办督查 → [节点5] 反馈销号
```

## 节点明细

### 节点 1：立项登记（找谁：督办机构——本单位办公室/督查室）

| 项 | 内容 |
|---|---|
| 来源 | 上级交办/领导批示/会议议定/重点任务/巡视审计整改 |
| **台账登记** | 一事一项编号：事项内容/来源/办结标准/办理期限/主办单位/办理状态 |
| 要点 | 立项分级：紧急（1 日部署 3 日办结）/常规（7-15 日）/重大（30 日）/长期（每月汇报阶段性成效） |

### 节点 2：交办分办（找谁：承办单位）

| 项 | 内容 |
|---|---|
| **公文①** | **督查督办通知单（govdoc-notice 简式）**——牵头单位/协办单位/办结时限/办理要求 |
| 要点 | 2 个工作日内完成责任分解；明确牵头与协办；"谁经办谁交办谁督办" |

### 节点 3：承办办理（找谁：牵头单位 + 协办）

| 项 | 内容 |
|---|---|
| **公文②** | **初步工作计划（报告简式）**——收到通知后 5 个工作日内报送 |
| **公文③** | **办理进展报告（govdoc-report）**——每月定期报送进展与次月安排 |
| 要点 | 难以按期完成的须**书面**报困难与对策建议（不允许口头拖延）；协同事项牵头汇总上报 |

### 节点 4：催办督查（找谁：督办机构）

| 项 | 内容 |
|---|---|
| **公文④** | **催办通知（govdoc-notice 简式）**——临期催办/多次催而不办的通报 |
| 要点 | 催办方式：电话/发函/派员/约谈；月度季度半年集中催办；通报与绩效考核、评优挂钩 |

### 节点 5：反馈销号（找谁：督办机构 + 交办机关）

| 项 | 内容 |
|---|---|
| **公文⑤** | **办结申请/办结报告（govdoc-report）**——事实清楚/定性准确/处理恰当/手续完备 |
| **公文⑥** | **延期申请（请示简式）**——确需延期的经批准后报交办单位备案（注明原因与批准意见） |
| 要点 | 办结销号制；未按要求办理的不予销号并继续督办；督办材料立卷归档 |

## 银川"135"机制（高频简化版，可作参数模板）

1 天内登记流转 → 3 天内调查核实 → 5 天内办结答复（重点事项闭环）

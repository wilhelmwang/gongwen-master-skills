# 工程建设项目招投标流程场景卡（tendering）

> 依据：《招标投标法》及实施条例 + 各地公共资源交易规则通行做法（详见 regulations.md）。
> 适用：工程建设项目（施工/货物/服务）依法必须招标的全流程公文。
> 与 procurement 场景卡的边界：本卡管**招投标法线**（工程项目为主），procurement 管**政府采购法线**（货物服务为主），两法衔接时按项目性质适用。

## 流程总览（6 节点）

```
[节点1] 项目审批+招标方案核准 → [节点2] 招标公告/文件 → [节点3] 开标评标
→ [节点4] 中标公示与通知书 → [节点5] 合同签订备案 → [节点6] 履约与投诉处理
```

## 节点明细

### 节点 1：项目审批 + 招标方案核准（找谁：发改部门）

| 项 | 内容 |
|---|---|
| **公文①** | **招标事项核准申报表 + 招标方案（随可研报批）**——招标范围/方式/组织形式 |
| 要点 | 招标事项在可研批复中一并明确，不得随意改变；确需改变的报原审批部门批准 |

### 节点 2：招标公告与文件（找谁：公共资源交易平台）

| 项 | 内容 |
|---|---|
| **公文②** | **招标公告（govdoc-notice 对外）**——媒介：中国招标投标公共服务平台/省级电子交易平台 |
| **公文③** | **招标文件**（法定文本）——评标办法/废标条款/合同条款 |
| 要点 | 公告期 ≥20 日（法定）；电子招标按平台规则；资格审查方式（预审/后审） |

### 节点 3：开标评标（找谁：评标委员会）

| 项 | 内容 |
|---|---|
| **公文④** | **评标报告（govdoc-report）**——评标委员会签署，推荐中标候选人（1-3 名排序） |
| 要点 | 评标委员会 5 人以上单数、专家≥2/3；否决投标须说明理由 |

### 节点 4：中标公示与通知书（找谁：招标人）

| 项 | 内容 |
|---|---|
| **公文⑤** | **中标候选人公示（govdoc-notice）**——公示期 ≥3 日 |
| **公文⑥** | **中标通知书（govdoc-letter）**——对中标人和未中标人同时发出，告知结果 |
| 要点 | 公示期异议 3 日内提出；中标通知书对招标人和中标人具法律约束力 |

### 节点 5：合同签订备案

| 项 | 内容 |
|---|---|
| **公文⑦** | **合同签订 + 备案（govdoc-letter 合同类）**——中标通知书发出 30 日内订合同；主要条款不得背离招标文件与投标文件 |
| 要点 | 履约保证金（≤中标合同金额 10%）；合同报监管部门备案 |

### 节点 6：履约与投诉处理

| 项 | 内容 |
|---|---|
| **公文⑧** | **投诉处理决定（govdoc-letter）**——投标人异议→投诉（异议答复期 3 日；投诉处理 30 日） |
| 要点 | 履约变更从严（重大变更报原审批部门）；转包违法分包禁止 |

## 与政府采购的衔接要点

工程项目达政府采购限额的：同时编采购预算（procurement 节点1）+ 走招投标程序（本卡）；适用两法的项目按项目性质与当地规定判定，起草时先确认适用法。

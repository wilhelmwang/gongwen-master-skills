# 路由规则权威副本（routing-rules.md · v8.1.0）

> 本文件为 gongwen-master 规则 A–F 精确命中表的**逐字镜像**，供人读、宣讲与代码审阅。
> **运行时权威源是 `SKILL.md` 的 Step 2.5**——`router.py` 的 `load_rules()` 解析的是 SKILL.md，不是本文件。
> 因此改动规则表须**先改 SKILL.md**，再把本文件同步为同一内容；两处不一致时以 SKILL.md 为准。
> 回归工具：包根 `rules_regression.py`（64 样例 → PASS 64/64）。

#### 匹配优先级

```
关键词命中（规则 C2 数据 > C 引用 > B 风格 > A 文种 > D 新手[带新手信号时提前] > E 动作）> 语义路由兜底（v6.9.0：口语查询向量匹配，`semantic_router.py` route_semantic，阈值 0.55，评测基线 93%/90 条）> 五维意图解析 > LLM 语义路由（Step 1/2）> 保底框架（Step 4）
```

**注意**：关键词命中需至少匹配到**一个完整关键词**（非子串），避免"报告"等高频词误触发。多关键词同时命中时，按优先级 C > B > A > D > E 路由；**但请求含新手信号（不知道怎么写/不会写/怎么开始等）时，D 优先于 A/B**（新手先引导，不直接写）。

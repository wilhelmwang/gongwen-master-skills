# 书籍行文 · 九风格合一（shuji v6.8.0）

> 九种书籍行文风格统一入口：路由 → 加载完整方法论 → 写作。
> 完整方法论存于 `references/<style>/SKILL.md`（渐进式披露）。

## 风格路由表

| 风格 | 触发词 | 来源书 | 核心特征（摘要） |
|---|---|---|---|
| **置身事内体** | 置身事内体 / 用它风格写 / 政府与经济 | 《置身事内》兰小欢 | 上下篇结构（微观机制-宏观现象）；财政-土地-债务主线；学术化但通俗 |
| **以利为利体** | 以利为利体 / 账本体 / 财政叙事 | 《以利为利》周飞舟 | 财政关系实证叙事；分税制/土地财政因果链；数据+制度解释并重 |
| **结构性改革体** | 结构性改革体 / 黄奇帆式 | 《结构性改革》黄奇帆 | 问题-结构-对策三段；市场化纵深改革视角；产业经济分析 |
| **转型政府体** | 转型中的地方政府体 / 官员激励 | 《转型中的地方政府》周黎安 | 行政发包制/政治锦标赛；官员激励与治理立论 |
| **制度逻辑体** | 制度逻辑体 / 组织分析 | 周雪光系列 | 组织与制度分析框架；合法性/效率张力 |
| **现象中国体** | 现象中国体 / 中国现象叙事 | 《现象中国》 | 宏观现象叙事；社会转型观察 |
| **当代政府体** | 当代政府体 / 政府运作 | 《当代中国政府》 | 政府机构与运作过程分析 |
| **中县干部体** | 中县干部体 / 基层干部 | 中县干部田野 | 基层干部晋升/关系田野叙事；（只取方法，不取立场） |
| **小镇喧嚣体** | 小镇喧嚣体 / 深描体 / 田野叙事 | 《小镇喧嚣》吴毅 | 乡镇政治运作深描；场景-人物-过程白描 |

## 使用流程

```
Step 1 路由：按触发词选风格（拿不准问一句）
Step 2 加载：references/<style>/SKILL.md 完整方法论
Step 3 写作：按该书的行文 DNA（结构/句式/论证取材/叙事视角）
Step 4 交付：附「公文大师下一步建议」
```

## 关键规则

- 只学习行文方法，只抽短句引文；不复制原文段落
- 各书蒸馏方法论含：结构骨架 / 句式特征 / 论证取材 / 示例模仿——按需加载对应 references

# xingwen-fangfa · 行文方法详解（dangdai-zhengfu v1.0.0）

> 取自《当代中国政府与政治》正版全文（301,075 字符/67 sections）量化实证。

## 一、宪法教科书体（核心签名）

**特征**：超40字长句占 51.6%（八书最高），均句长 47.3 字——一个句子讲清一个制度关系。

**范式**：
```
党的各级组织在[具体领域]中承担[具体职能]，这一职能通过[制度机制]来实现，其目的在于[制度目标]，而在实际运行中，[补充说明/限制条件]。
```

**要点**：
- 主语一定是制度主体（党/人大/政府/政协）
- 一句话讲清权力来源、运行机制、制度目标
- 不拆成多个短句——保持信息密度

---

## 二、党轴心平铺

**特征**：以"党"为叙事轴心（3,478次，八书最高），全书按制度层级顺序平铺——不设问、不制造悬念。

**结构模板**：
```
（一）[制度主体]的性质与地位
   → 宪法依据 + 党章规定 + 历史沿革
（二）[制度主体]的组织体系
   → 中央→省→市→县→乡 五级展开
（三）[制度主体]的运作机制
   → 决策→执行→监督 三环节说明
（四）本章小结
   → 综上所述，[制度主体]在[领域]发挥[作用]...
```

---

## 三、学术转折词网络

**特征**：67处设问之外，大量使用学术转折词推进叙事——"事实上"23/"可以说"14/"值得注意的是"8/"正如"5。

**使用场景**：
- "事实上"——转折到实然层面（实际运行与制度规定不一致时）
- "可以说"——判断式总结（给一个制度定性）
- "值得注意的是"——引导读者关注关键细节
- "正如"——引述经典论述或宪法条文

**公文适配**：
- 政策研究报告用"事实上"引出实施中的问题
- 制度分析用"可以说"下判断
- 调研报告用"值得注意的是"突出发现

---

## 四、本章小结收束

**特征**：13 次"本章小结"（八书最高），每章末标准收束——不交棒（0次"下一章"）、不强下结论（仅4次"结论"）。

**收束句式模板**：
```
本章小结：以上分析表明，[制度主体]在[领域]的运作呈现出[特征]，其核心逻辑在于[机制]，但在实际运行中也面临着[问题]。
```

**公文适配**：
- 报告各节末用"综上所述""本节小结"收束
- 不预告下一节——保持各节独立性

---

## 五、低数字高概念密度

**特征**：数字密度仅 1.86%（八书第二低），表格仅 20 处——全书靠概念密度推进，不靠数据叙事。

**核心词频率**：

- 制度 879

**公文适配**：
- 政治理论学习材料用概念密度推进

- 党建汇报用"党"为高频主语

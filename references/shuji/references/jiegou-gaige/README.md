## 量化基线
- 均句长：45.9 字（七书最长）
- 超40字长句：49.7%（七书最高——决策者权威口吻签名）
- 设问：88 处
- 例证：48 + 100（例如 + 如，）
- 数字密度：3.11%
- 签名结构：无明显装置（纯以内容密度推进）

## 模块签名
**决策者长句型**——七书中唯一的决策者口吻模块。超40字 49.7% = 近半句子超过40字，这是做了几十年决策的人说话的方式：一个句子就是一个完整政策判断。

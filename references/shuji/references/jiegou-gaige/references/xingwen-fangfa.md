# xingwen-fangfa · 行文方法与风格画像（jiegou-gaige v1.0.0）

> 《结构性改革》（黄奇帆）正版全文逐章分析。量化基线：均句 45.9 字 / 超40字 49.7% / 设问 88 / 数字 3.11%。

## 一、逐章叙事弧

### 第一章：深入推进供给侧结构性改革
**起**：以"紧抓主线"开篇，直接给出改革总纲
**承**：土地要素市场化→金融供给侧→要素配置→公共卫生，四个措施并列
**转**：从"应该改"转向"具体改什么"
**合**：以"全面深化改革新突破"收束

### 第二章：去杠杆与金融风险防范
**起**：设问"如何打赢去杠杆攻坚战？"——问题导向入口
**承**：金融本质→全生命周期风险→P2P→股权融资，逐层深入
**转**：从"防范风险"转向"主动改革"
**合**：以"提高股权融资比例"收束——给出出路

### 第三章：新时代资本市场高质量发展之路
**起**：历史回顾"发展历程、功能及不足"
**承**：十二条建议→注册制与退市→年金→公积金→香港，逐条措施
**转**：从制度层面扩展到资金来源
**合**：以"香港资本市场再出发"收束——视野扩展

### 第四章："数字化"重塑经济社会生态
**起**：新特征新趋势——宏观判断
**承**：数字货币→5G金融科技，两条主线
**转**：从技术趋势转向政策应对
**合**：以具体发展建议收束

**逐章弧总结**：每章独立成篇→问题入口→措施并列→给出出路。不交棒、不收束，纯以内容密度推进。

## 二、决策者长句写作模板

### 模板 A：政策判断长句
```
[背景/现状]，[问题所在]，[应采取的措施]，[预期效果/目标]。
```
示例结构："当前资本市场存在[问题]，根本原因在于[原因]，应当从[措施]入手，实现[效果]。"

**硬指标**：单句 ≥ 40 字；一个句子表达一个完整政策判断；禁止拆成多个短句。

### 模板 B：措施清单体
```
第N条：[措施名称]——[具体做法]，[量化目标]，[实施路径]。
```
示例结构："第二条：完善退市制度——建立常态化退市机制，每年退市率不低于X%，通过[路径]实现。"

### 模板 C：三轴论证体
```
从[金融维度]看，[分析]；从[市场维度]看，[分析]；从[制度维度]看，[分析]。因此，[综合结论]。
```
**关键**：每个论点至少覆盖两个轴，避免单维度。

### 模板 D：问题导向入口
```
[设问]？[现状描述]。[原因分析]。[措施建议]。
```
示例结构："如何打赢去杠杆攻坚战？当前企业杠杆率偏高。根本原因是[原因]。建议从[措施]入手。"

## 三、反AI味自检

- [ ] 句子是否够长？（超40字 ≥ 40%）
- [ ] 是否每个论点覆盖金融/市场/改革两轴以上？
- [ ] 措施是否可执行？（禁止"应加强""应完善"式空话）
- [ ] 数字是否锚定政策颗粒度？（禁止泛泛"大幅""显著"）
- [ ] 口吻是否像决策者在说话？（禁止"笔者认为""有学者指出"式学术腔）

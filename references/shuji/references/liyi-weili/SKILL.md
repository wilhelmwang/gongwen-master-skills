# liyi-weili · 以利为利行文模块（财政实证叙事法）

基于周飞舟《以利为利：财政关系与地方政府行为》正版全文（316 页 / 20.7 万字符）逐章精读蒸馏。与 shizhi-shinei（置身事内·宏观叙事）互补：**置身事内讲"政府怎么投融资"的故事，以利为利讲"钱从哪来、怎么分、怎么用"的账本**——适合财政/经济治理类公文，立论靠表格与数字，不靠修辞。

## 一、六法（按本书实际签名排序）

### 法一：表格立骨（签名装置，本书最强特征）
全文 389 处引用"表"——每个关键论断后面几乎都站着一张表。
- 用法：**先结论，再上表**；表格是证据不是装饰。
- 例："企业收入由1950年占财政收入的13.4%，到'一五'时期的最后一年，这个比重上升到了46.5%"（表证同步）。
- 公文转化：政策分析报告里，每个机制判断配一张数据表/一张对比表，替代空泛描述。

### 法二：超短句稳节奏（0.7% 长句）
均句 20.2 字，超 40 字长句仅 0.7%——三本政府运作书里句子最短最平。
- 用法：一句一断，因果链拆成短句推进；不堆定语从句。
- 公文转化：写财政/经济分析时，把"由于……因此……从而……"长句拆成 3-4 个短句。

### 法三：机制三层论证（财政链条）
层层递进的财政机制链：**分税制改革 → 转移支付体系 → 县乡财政危机 → 土地财政 → 土地金融"三位一体"**。
- 用法：先立制度（分税制），再追资金流向（转移支付/专项化），最后推到行为模式（土地财政/经营城市）。
- 例：序论"政府行为与中央—地方关系"→ 第四章"分税制改革及其影响"→ 第十三章"土地财政"→ 第十四章"土地金融和城市化：'三位一体'的发展模式"。

### 法四：设问牵引（78 处）
每章从真问题切入，设问是章节引擎。
- 例："政府的行为是理性的还是非理性的？""权力为什么没有明显地阻碍经济增长？""分税制的效应如何？""地方政府通过何种途径促进经济增长？"
- 公文转化：分析段以"问题—机制—证据—结论"四拍展开，设问开头。

### 法五：数字徽言（密度 4.51%）
用精确数字立信，百分比、亿元、占比是叙事主体。
- 例："75%归中央，25%归地方""企业收入……上升到46.5%""始终占总收入的35%左右"。
- 公文转化：任何判断给数字；占比变化本身就是论证。

### 法六：结论收束 + 章节互引
每章末设"结论"节（全书 11 次），章内回指"上一章"（7 次）保持链条感。
- 用法：章末用 3-5 段独立收束本章判断，不抒情、不拔高，只把机制结论钉死。
- 公文转化：报告每节末尾给"结论段"，章节之间用"如上一章所述"衔接。

## 二、硬指标（写作自检）
- [ ] 均句长 ≤ 22 字；超 40 字长句占比 ≤ 2%
- [ ] 每个机制论断配 ≥1 处数字或表格引用
- [ ] 全文设问 ≥ 3 处（每章 ≥1）
- [ ] 章/节末有独立"结论"段
- [ ] 数字密度 ≥ 3.5%
- [ ] 不复制原文整段（版权红线：仅短句引文并注明《以利为利》出处）

## 三、使用场景
财政预算/决算报告、税收政策分析、土地与城市经营调研、央地关系与转移支付研究、经济治理类公文、调研报告的"资金流向"章节。

## 四、与 shizhi-shinei 的分工
- 讲故事、讲格局、讲人 → 置身事内模块（小切口/历史纵深/金句收束）
- 讲账本、讲机制、讲证据 → 以利为利模块（表格立骨/短句/数字/结论收束）
- 组合建议：经济治理类公文正文用 liyi-weili 立论，开头结尾用 shizhi-shinei 升华。

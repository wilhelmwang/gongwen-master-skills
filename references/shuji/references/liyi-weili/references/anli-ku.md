# anli-ku · 机制案例库（liyi-weili v1.0.0）

> 从《以利为利》正版全文核验的财政机制案例链（短句引文+机制概括），供公文写作调用。版权：仅概括与短引文，注明《以利为利》出处。

## 一、制度转折案例（链条起点）

### 1. 分税制谈判（1994）
- 机制：增值税 75% 归中央、25% 归地方 → 地方财权收缩、事权不变 → 被迫寻新财源。
- 原文引："75%归中央，25%归地方"
- 公文用法：制度变革如何改变行为主体激励——"分成比例即行为指挥棒"。

### 2. 财政包干时期（1980s）
- 机制：包干制下地方留存比例高 → 地方有激励办企业 → "放权让利"推动乡镇企业。
- 公文用法：激励相容的制度设计范例。

## 二、链条断裂案例（问题诊断）

### 3. 县乡财政危机（第六章）
- 机制：分税制后财权上收、事权下放 → 县乡财政入不敷出 → 基层靠"三提五统"和借债。
- 公文用法："财权事权不匹配"的诊断模板。

### 4. 基层政权"悬浮"（第七章）
- 机制：财政资源向上集中 → 基层政府脱离农民、脱离公共服务 → "悬浮"于乡土之上。
- 原文引："实际上，这也正是乡镇一级财政存在并能发挥作用的意义所在"
- 公文用法：财政供给与治理触达的关系论证。

### 5. 资金"专项化"（第八章）
- 机制：转移支付以专项资金形式下达 → 地方自主空间压缩 → "跑步钱进"。
- 公文用法：资金形式如何改变治理行为。

## 三、模式成型案例（土地财政闭环）

### 6. 土地征用与土地收入（第十二章）
- 机制：征用农地 → 出让金归地方 → 土地成为最大财源。
- 原文引："这些土地和厂房在正式的国土管理中根本还是养鱼种粮的农地"（征地反差）

### 7. 土地财政（第十三章）
- 机制：土地出让金 + 土地相关税费 > 全部政府收入 50% → 经营城市。
- 原文引："市场经济的发展、工业化和城市化恰恰为地方政府开辟生财之道"

### 8. "三位一体"发展模式（第十四章）
- 机制：土地 + 财政 + 金融闭环——政府注入土地到融资平台 → 平台举债 → 基建 → 地价上涨。
- 公文用法：模式化表述"土地—财政—金融三位一体"。

## 四、应用指引
- 制度分析 → 用案例 1-2（分税制/包干）
- 基层治理诊断 → 用案例 3-5（县乡危机/悬浮/专项化）
- 土地与城市经营 → 用案例 6-8（征地/土地财政/三位一体）
- 每个案例都可拆成：机制一句话 + 数字支撑 + 因果链三步。

## 这是什么

把兰小欢《置身事内：中国政府与经济发展》（上海人民出版社 2021，文津奖）的**行文方法论**蒸馏成一个可用的写作模块：
- **七维行文手法**：小切口大纵深 / 机制三层论证 / 数字徽言大义 / 比喻化繁为简 / 历史纵深开合 / 自问自答牵引 / 金句收束升华
- **签名结构装置**：每章结语"交棒下一章"（全文"下一章"恰好 8 次）；章末"扩展阅读"挂文献
- **"置身事内"立场纪律**：务实、具体、不贴标签、同情之理解、人本收束
- **经济治理叙事骨架**：上篇微观机制 → 下篇宏观现象 → 务实方向判断

## 适用场景

写**经济形势分析、发展改革类领导讲话、工作报告经济部分、调研报告、政策说明、改革叙事**时，让文稿"把机制讲成门道、把数字讲回生活"。

## 模块内容

```
shizhi-shinei/
├── SKILL.md                      # 主技能（角色+七法+立场+流程+质量标准）
└── references/
    ├── xingwen-fangfa.md         # 行文方法论（逐章叙事弧/风格画像/模板/反AI味）
    ├── jingju-kuzi.md            # 金句与素材库（判断句/设问句/数字金句/口语化/术语速查）
    └── anli-ku.md                # 案例库（机制→案例对照/套用脚本）
```

## 怎么用

对 AI 说："用置身事内体写这段经济形势分析"／"把这段发展改革讲话改成'讲机制'的写法"／"给我一个讲土地财政的比喻"，即可按本模块行文。

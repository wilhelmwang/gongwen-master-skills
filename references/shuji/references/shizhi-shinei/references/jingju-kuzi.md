## 二、自问自答·设问牵引句（v2.0 新增，取自全文 100 处问号）

这些问句是兰式"提问—作答"节奏的范本，写稿时可直接改用词复用：

- "政府究竟是如何融资和投资的？"（第三章开宗设问，整章问题一句话抛出）
- "区区三尺土地，为什么一旦变成房本，别人就得拿大半辈子的收入来换？"（第五章刺痛感开题）
- "都是地，人家的怎么就那么值钱？"（土地价值反差设问）
- "市场如果有效，为什么会有企业？"（讲政府干预的合理性）
- "只要中央做了决策，地方不就只有照办的份儿吗？"（讲分税制谈判之难）
- "一件事该不该做？"（讲政府工作千头万绪）
- "可是制度一直如此，为什么前些年问题似乎不大？"（讲时变与累积风险）
- "行业和企业如何借力政府来发展？政府资金如何投入和退出，又如何影响行业兴衰和技术起落？"（第四章双设问，框定全章）

**用法**：每节开头抛一个"为什么/怎么办"，正文回答；读者被牵着走。平均 2000 字至少一个设问。

## 三、内嵌的"数字金句"（反差数据示例）

- 地方预算支出占全国 85%，收入只占 50%—55%（转移支付填空缺）
- 2018 年"土地财政"收入 ≈ 地方公共预算收入的 89%——名副其实的"第二财政"
- 土地出让收入：2003 年达地方公共预算收入 55% → 2010 年 68% → 2018 年 62910 亿元
- 地方财政供养人员 1994—2005 年：2981 万 → 4778 万（增 60%）
- 1992 年地方预算外收入达预算内收入的 86%
- 我国居民储蓄率 90 年代 25%—30%，同期美国仅 6%—7%
- 2008"4万亿"：中央 1.18 万亿，地方 2.82 万亿；城投公司 2008 年 3000 余家→2009 年 8000 余家
- 哈佛民调：认为地方官员"比较清廉"的比例 2011 年 35% → 2016 年 65%

## 五、制度名词速查（写作时的术语准确性）

| 术语 | 含义 |
|---|---|
| 分税制（1994） | 按税种划分央地与省以下收入，影响深远的分水岭 |
| 财政包干/分灶吃饭 | 1980 年代央地财政关系：地方留存 + 上解 |
| 土地财政 | 土地出让收入 + 与土地开发相关税收（第二财政） |
| 招拍挂 | 经营性用地招标/拍卖/挂牌出让制度（2002 起） |
| 土地一级/二级开发 | 生地整理成熟地（政府平台）→ 建设运营（房企） |
| 城投/融资平台公司 | 政府背景、以土地抵押/隐性担保融资的投融资主体 |
| 4万亿（2008） | 应对国际金融危机的财政刺激 |
| 三道红线 | 房企负债率/净负债率/现金短债比三条监管红线 |
| 供给侧结构性改革 | 2012 十八大后系统推进的结构性改革 |
| 库兹涅茨曲线 | 收入不平等随经济增长先升后降的"倒U"假说 |
| 乡财县管 / 省直管县 | 财政管理权向上集中的两种改革 |

# 置身事内体 · 行文方法论 v2.0.0

> 蒸馏自兰小欢《置身事内：中国政府与经济发展》**全文 300 页逐章精读**（上海人民出版社 2021）。
> 用途：经济治理类公文/文稿的行文指导。原文版权归作者与出版社，引文请注明出处，且只作短句摘录。

## 一、全书结构（可复用的经济治理叙事骨架）

| 篇 | 章 | 主题 | 叙事抓手（小切口） |
|---|---|---|---|
| 上篇·微观机制 | 一 | 地方政府的权力与事务 | "行政区划面积该不该相等"的反常一问 |
| | 二 | 财税与政府行为 | 分税制谈判的艰难（朱镕基带队逐省谈） |
| | 三 | 政府投融资与债务 | "政府究竟如何融资和投资？" |
| | 四 | 工业化中的政府角色 | 京东方/合肥、光伏产业的"故事" |
| 下篇·宏观现象 | 五 | 城市化与不平衡 | "三尺土地变房本，为何要拿半辈子收入换" |
| | 六 | 债务与风险 | 欧美教训 → 中国债务与化解 |
| | 七 | 国内国际失衡 | 低消费、产能过剩、中美贸易冲突 |
| | 八 | 政府与经济发展（总结） | 地区竞争、发展转型、务实前景 |

**叙事公式**：上篇讲"机制是怎么转的"，下篇讲"转出来的结果与代价"，最后给"往哪转"的判断——即 **机制→结果→方向** 三段式。上篇是"因"，下篇是"果"，第八章收束为"务实观"。

## 二、每章"起承转合"叙事弧（v2.0 逐章提炼）

- **第一章 权力与事务**：反常设问（面积该相等吗？）→ 外部性/规模经济/复杂信息/激励相容 → 招商引资实例 → 结语收束事权划分，交棒"财权划分"。
- **第二章 财税**：分税制谈判故事（中央决策，地方为何难照办？）→ 包干制→分税制→土地财政→纵向/横向不平衡 → 结语指"债务是下一章"。
- **第三章 投融资与债务**：开宗问"政府如何融资投资"→ 城投与土地金融→地方债→招商中的地方官员 → 结语点"债务情况下一章讲"。
- **第四章 工业化中的政府**：京东方（合肥托底、吃过夏普亏）、光伏（尚德/赛维造富与破产）、产业引导基金 → 结语"光电、光伏、高铁的故事，下一章接着讲"。
- **第五章 城市化**：房本之问 → 房价与居民债务→不平衡与要素市场→贫富差距 → 结语收束"以地为本、忽略人"的代价。
- **第六章 债务与风险**：债务与经济衰退（欧美教训）→ 中国债务全景 → 化解风险 → 结语指"失衡与再平衡"。
- **第七章 国内国际失衡**：低消费与产能过剩→中美贸易冲突→国内大循环 → 结语收束结构失衡。
- **第八章 总结**：地区间竞争→政府发展与转型→目标与过程 → 结束语"生活过得好一点，比大多数宏伟更宏伟"。

**共通弧线**：`反常小问/现场故事（起）→ 机制链铺开（承）→ 现实结果与代价（转）→ 判断句+交棒下一章（合）`。

## 三、风格量化画像（v2.0 来自全文统计）

| 指标 | 数值 | 可操作标准 |
|---|---|---|
| 平均句长 | 19.8 字 | 一句一意，长句占比压到 5% 以内 |
| 设问（？） | 100 处 / 21 万字 | 每 2000 字至少一个"为什么"，自问自答 |
| 例证标记 | 195 处 | 几乎每段一个案例或比方 |

## 四、起承转合模板（经济形势/调度讲话）

- **起**：一个叛逆性小事实（工厂订单/园区案例/反差数字）→ 抛出"为什么"
- **承**：机制链铺开（制度根源→行为逻辑）
- **转**：现实结果与代价（数据+案例+历史纵深）
- **合**：务实判断 + 改革方向 + 一句信念收束 + （系列稿）交棒下一节

## 五、反AI味自检（经济文体特有）

- 避免"今年以来，我国经济稳中向好……"式八股开头 → 用现象/案例/数据开题
- 避免"一方面…另一方面…"平衡句式 → 直接给机制判断
- 避免"加强、推进、落实"万能动词堆叠 → 落到具体机制与数字
- 避免"让我们共同努力"空洞收尾 → 用判断句/信念句
- 避免通篇术语无比方 → 每个复杂机制配一个日常比喻

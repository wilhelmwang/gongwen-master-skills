## 一、清单制膨胀机制

**问题**：基层治理中的"清单依赖"——上级部门把工作任务转化为清单，层层下压。

**机制拆解**：
1. 县局A发清单→乡镇执行→县局A考核
2. 县局B发清单→乡镇执行→县局B考核
3. N个县局发N份清单→乡镇同时执行N份→精力稀释→形式主义
4. 结果：台账从3本变27本，干部时间花在填表而非干事

**公文调用**：用"清单膨胀"揭示形式主义根源——不是干部不想干，是制度设计让精力分散。

## 二、属地管理的责任转嫁

**问题**：属地管理本意是"谁主管谁负责"，实际变成"谁在基层谁负责"。

**机制拆解**：
1. 县局有执法权但人手不足→把执法任务"下沉"到乡镇
2. 乡镇没有执法权但被考核→被迫"违法执法"
3. 出了问题→县局说"是乡镇执行的"→乡镇背锅
4. 结果：权力上收，责任下沉，权责不对等

**公文调用**：用"权责不对等"框架分析基层治理困境——制度层面的结构性问题。

## 三、考核权重决定资源配置

**问题**：乡镇把精力放在哪里，不取决于群众需求，而取决于考核权重。

**机制拆解**：
1. 环保考核权重提高→乡镇全员抓环保
2. 招商考核权重提高→乡镇全员跑招商
3. 维稳考核权重提高→乡镇全员盯信访
4. 结果：群众最需要的事（比如养老服务）因为没有考核指标而被忽视

**公文调用**：揭示"考核指挥棒"如何扭曲基层行为——制度激励分析。

## 四、干部晋升天花板与躺平

**问题**：基层干部晋升空间有限，理性选择是"不求有功但求无过"。

**机制拆解**：
1. 县级干部职数有限→多数乡镇干部止步于科级
2. 晋升靠考核排名→考核靠指标完成→指标靠形式主义
3. 躺平收益（低压力+稳定收入）> 奋斗收益（高风险+有限晋升）
4. 结果：能干事的干部流失，留下的选择不出头

**公文调用**：分析基层干部激励困境——制度设计与人性博弈。

## 五、条块矛盾的日常化

**问题**：县局（条）与乡镇（块）之间权责不清，矛盾日常化。

**机制拆解**：
1. 县局发文：请各乡镇落实XX工作
2. 乡镇执行：缺人、缺钱、缺权
3. 县局考核：未完成，扣分
4. 乡镇反馈：你们不给资源，让我们怎么干？
5. 结果：年年喊减负，年年负担重

**公文调用**：用"条块矛盾"框架分析基层治理的结构性困境。

# anli-ku · 现场案例库（xiaozhen-xuanxiao v1.0.0）

> 从《小镇喧嚣》正版全文核验的乡镇政治"现场"清单（主题场景概括，非逐字引文）。供调研/经验材料调用。版权：仅概括，注明《小镇喧嚣》出处。

## 一、六大现场（全书叙事单元）

### 1. 迎检现场（乡镇政治的"表演性"）
- 场景：上级检查前的材料准备、接待陪同、口径统一。
- 机制：迎检是"政策执行的可视化表演"——材料即政绩。
- 公文用法：写形式主义/基层减负，用"迎检一天、备战一月"式现场。

### 2. 开发的政治学（第二章）
- 场景：云宏铁业/开发区征地——资本、政府、农民三方进场。
- 机制：开发不是纯市场行为，是"政治—经济"复合博弈。
- 公文用法：招商引资案例的"多方博弈"叙事。

### 3. 征收税费现场
- 场景：农业税费时代的收与支、基层的催收困境。
- 机制：税费征收考验政权与农民的"面对面"关系。
- 公文用法：写惠农政策前后对比，用征收现场做旧景。

### 4. 产业调整现场
- 场景：结构调整中乡镇企业与政府的互动。
- 机制：产业政策落地的乡镇版本。
- 公文用法：产业转型调研的基层切面。

### 5. 征地"种房"现场
- 场景：征地通知后村民连夜抢建，补偿博弈白热化。
- 机制：规则与绕规则的拉扯——"种房"是农民对补偿规则的反制。
- 公文用法：征地拆迁案例的"规则博弈"叙事。

### 6. 维权争利现场
- 场景：村民、干部、企业三方过招，信访与调解。
- 机制：维权不是零和，是"博弈—平衡—暂告段落"。
- 公文用法：信访矛盾调处的"余波式"结案叙事。

## 二、叙事公式（场景→公文）
每个现场可转化为公文段落：
```
开锣（时间地点事件一句）→ 人物（有名有姓双方）→
对话（原话一来一回）→ 博弈（规则与绕规则）→
余波（暂告段落，留白）
```

## 三、应用指引
- 典型经验材料 → 现场 1（迎检表演）+ 现场 4（产业调整）
- 征地拆迁调研 → 现场 2 + 现场 5（开发/种房）
- 信访与基层治理 → 现场 3 + 现场 6（税费/维权）
- 反形式主义材料 → 现场 1（迎检）

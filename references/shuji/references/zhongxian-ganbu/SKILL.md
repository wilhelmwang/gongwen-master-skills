## 一、六法

### 法一：数字徽言（核心签名）
用「比例 + 职级 + 周期」构造一句话结论，数字本身成为论证。
- 句式模板：`从X来看，Y占Z%，而W仅占V%。`
- 例：`从干部的家庭出身来看，60%来自于农家，20%来自于干部家庭。`（出处：《中县干部》）
- 例：`32名中县县领导有19名来自于农民家庭，占59%。`（出处：《中县干部》）
- 律条：**每一个论断必须挂一个数字；没有数字的论断不出现在正文。**

### 法二：任职周期表（时间轴量化）
用「到某级需几年」把成长路径变成可计算的爬坡曲线。
- 例：`科员一般约8年，副科到正科约3年，正科到副处约7年，副处到正处约7年。`（出处：《中县干部》）
- 模板：`A到B约X年，B到C约Y年，C到D约Z年`——时间阶梯式排比，节奏感强。
- 用途：干部梯队分析、人才成长规划、任职年限研究。

### 法三：职级金字塔（结构白描）
用「X名副处级+ Y名正处级 + Z名科级」描摹干部队伍结构，不评价、只呈现。
- 例：`28名副处级领导和4名正处级领导。`（出处：《中县干部》）
- 模板：`全县干部队伍呈金字塔结构：正处级X人，副处级Y人，正科级Z人，副科级W人。`
- 关键：**结构即结论**——金字塔本身传达信息，无需额外判断句。

### 法四：访谈实录点缀（低密度对话）
全书以统计为主，但关键处插入访谈原话作为"活证"。
- 例：`"我们那有40多个女同志，副科级以上女领导干部有3-4人。"`（出处：《中县干部》访谈）
- 用法：论述枯燥处放一句当事人原话，形成"数据—人声"对位，每章至多 1-2 处。

### 法五：历史对照（1949-2000 长时段）
用组织史/干部名录做长时段对照，把横截面统计升级为纵向演变。
- 例：`《北山干部任免名录1949—2000》`（出处：《中县干部》档案引用）
- 模板：`对比X年与Y年同一指标：Z从A%变为B%`——演变成趋势，趋势成论证。

### 法六：审慎设问（中高密度但克制）
118 处设问，多为"为什么"型结构问题，问完必答、答必带数。
- 模板：`为什么会出现这种现象？从数据看，……`
- 纪律：**先问后答、答必有据；问而不答是禁忌。**

## 二、叙事弧（数据驱动的"三段落差"）

1. **高峰**：开头给出一个反直觉数字（如比例最高的群体）
2. **平谷**：中段用表格/周期逐项拆解（出身/学历/年龄/行业构成）
3. **落差结论**：末尾回归"数字背后的制度逻辑"，但不做价值判断

示例结构：
```
开：中县干部出身统计——60%农家、20%干部家庭（反直觉冲击）
中：按 8 大系统（口）拆解：党政口 X 人、教育口 Y 人……
   任职周期表：科员8年→副科3年→正科7年→副处7年
   年龄结构：正科一把手41-50岁占60%以上
落：数字背后的逻辑——政绩激励型体制的运作轨迹
```

## 三、硬指标（写作自检）

- [ ] 每个论断 ≥1 个数字支撑，无数字不立论
- [ ] 数字占比目标 5%+（全书基准 5.90%）
- [ ] "例如"使用次数 ≤1（用数字替代例证）
- [ ] 访谈引语 ≤2 处/章，且必须标注来源身份
- [ ] 章节结尾不做强判断，用"数据显示…"收束

## 五、立场纪律（本模块特有）

1. 本书涉干部个体统计，**只取方法，不取立场**——不复制任何个案判断
2. 案例库全部去敏：无真实人名、无具体单位指向
3. 涉及敏感统计（如出身比例）时，仅作为方法论示范，不扩散原始数字
4. 若用于公文写作，优先以"本地干部队伍构成"的正面统计替换原书数据

## 一、方法骨架案例（可直接套用）

### 案例 1：出身结构分析（比例徽言骨架）
- 方法：统计各类出身占比 → 一手数据表格 → 一句话归纳结构
- 报表式段落骨架：
  ```
  【背景】全县X名领导干部中……
  【统计】A类Z%，B类W%，C类V%
  【收束】数据表明……（仅描述，不判断）
  ```

### 案例 2：任职周期图（阶梯骨架）
- 方法：从履历表提取各职级平均任职年限 → 排成时间阶梯
- 段落骨架：
  ```
  以X级为起点，到Y级约N1年，再到Z级约N2年。
  同期，从W级到V级需N3年。
  ```
- 用途：人才梯队规划、干部成长路径研究

### 案例 3：金字塔结构白描
- 方法：按职级/系统/年龄三组切片，各出一个数字
- 段落骨架：
  ```
  按职级：正处X/副处Y/正科Z/副科W
  按系统：党政口A、教育口B、政法口C……
  按年龄：41-50岁为主体，占60%以上
  ```
- 用途：干部队伍现状综述

### 案例 4：长时段对照（历史演变骨架）
- 方法：组织名录/人事档案 → 关键年份指标对比
- 段落骨架：
  ```
  对比1978年前后两条线：选拔来源、学历构成、任职时长
  ```
- 用途：干部人事制度改革回顾

## 二、干部梯队分析四问模板

写任何"干部队伍建设"材料前，先过四问：
1. **出身**：来源结构如何？（量化的第一刀）
2. **周期**：各级晋升需几年？（量化的第二刀）
3. **结构**：金字塔比例如何？（量化的第三刀）
4. **流向**：交流/提拔/退出如何分布？（量化的第四刀）

四问全有数字 → 报告自然成形。

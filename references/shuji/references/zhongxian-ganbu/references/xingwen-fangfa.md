# xingwen-fangfa · 行文方法详解（zhongxian-ganbu v1.0.0）

## 一、核心签名拆解：数字徽言为什么有效

《中县干部》全书只用 1 次"例如"，却完成了一部 31 万字的干部成长研究——秘密在于：
**每个判断都自带数字，数字即证据，证据即叙事。** 读者不需要作者说"普遍如此"，
只需看到"60%来自于农家"就自己完成归纳。

### 数字徽言的三个层次

| 层次 | 示例 | 用途 |
|---|---|---|
| L1 比例式 | 60%来自农家、20%干部家庭 | 结构判断 |
| L2 阶梯式 | 科员8年→副科3年→正科7年→副处7年 | 周期/路径 |
| L3 对照式 | 1978年前X%、1978年后Y% | 演变/趋势 |

## 二、数据呈现的四种句式

1. **总-分式**：`全县干部按行业分为8大系统，俗称口。` → 一句话划定框架，随后逐口拆解
2. **占比式**：`正科级一把手以41—50岁为主体，占了60%以上。` → 主体年龄+占比双锁定
3. **双数对比式**：`23名省委第一书记中，17名来自于关键省份。` → 总量包裹关键数
4. **差值式**：`除了20多名领导干部之外，乡机关160多人只允许保留53名。` → 对比制造张力

## 三、访谈实录的嵌入点

全书访谈只出现在两类位置：
- **章节开头**（引子）：一句当事人原话，立起本章主题
- **统计之后的落差处**：数据说完，用一句话"人声"回到现场

嵌入纪律：
- 每章 ≤2 处
- 必须标注访谈对象身份（"某乡镇党委书记谈到"）
- 不能代替数据，只能点缀数据

## 四、论文体的章节节奏（无章末装置）

本书无结论/结语/小结/下一章装置（215 页论文体），章节推进靠：
1. 现象切入（一个具体个案或数字）
2. 数据铺开（表格+比例）
3. 机制归纳（制度的运作逻辑，非价值判断）

> 对比提醒：zhongxian-ganbu 的"无收束"与 xianxiang-zhongguo 的"零收束"不同——
> 县乡中国是**叙述上**不总结，中县干部是**论证上**以全章数据自然收口。

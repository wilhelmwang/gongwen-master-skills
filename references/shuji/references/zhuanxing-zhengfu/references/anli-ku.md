# anli-ku · 机制案例库（zhuanxing-zhengfu v1.0.0）

> 从《转型中的地方政府》正版全文核验的激励机制案例（短句引文+机制概括），供公文写作调用。版权：仅概括与短引文，注明出处。

## 一、激励设计案例（行政发包制）

### 1. 层层加码（目标值递增）
- 机制：上级为防止下级懈怠，故意抬高目标 → 目标值逐级递增（省→市→县）。
- 原文引："于县级政府的目标值，而县级政府所订立的目标增长率又要高于所在……"
- 公文用法：考核指标设计的"激励悖论"诊断模板。

### 2. 属地化行政发包
- 机制：中央发包任务 → 地方属地内自由裁量 → 信息/监督/激励/控制四位一体。
- 公文用法：放管服改革的制度逻辑说明。

## 二、横向竞争案例（政治锦标赛）

### 3. 经济增长竞赛
- 机制：同级官员以属地经济增长为竞赛标准，优胜者晋升 → "以经济增长为基础的锦标赛是'协助之手'的最终来源"。
- 公文用法：区域竞争与重复建设的统一解释。

### 4. 政绩与腐败并存之谜
- 机制：晋升激励与财政激励组合因人而异 → 仕途无望者转向"堕落"。
- 原文引："上去不可理喻，仕途尚早为什么就开始堕落呢？"
- 公文用法：干部监督的激励结构分析。

## 三、政企关系案例（"官场+市场"）

### 5. 三种区域政企模式（苏南/温州/广东）
- 苏南：政企合一（乡镇政府直接经营企业，攫取动机下降）
- 温州：民营自组织（政府吸引力小，市场网络发达）
- 广东：政策特区（外资"大推进式"流入）
- 原文引："这正是苏南地区的比较优势所在"
- 公文用法：营商环境对比分析框架（政企关系三型）。

### 6. 诸城改革
- 机制：县级国企"放活"改革案例，检验行政发包与市场化的边界。
- 原文引："结论是诸城改革为'放活国有小企业'创造……"
- 公文用法：基层改革试点的机制评估。

## 四、应用指引
- 考核/激励设计 → 案例 1-2（层层加码/行政发包）
- 干部竞争与监督 → 案例 3-4（锦标赛/腐败之谜）
- 营商环境/政企关系 → 案例 5-6（三模式/诸城改革）

# 公文大师 · 团队角色名录（v2.0 · 2026-09-23）

> 雅正官称式命名：双字古雅、职能可辨，适合文书语境。替换角色只需改本表（编排手册按角色标识引用，不绑名字）。
> **两腿分列**：评审角色（场景 1-3）与写稿角色（场景 4-7，v8.1.0 新增）。

## 主理人

- **文衡**（文衡先生，orchestrator）——总编排与裁决，权衡文章之优劣（"文衡"=文章权衡）
  - 两腿共用。**不执笔**：评审腿只出综合报告与汇签；写稿腿只编排，执笔权在秉笔。

## 评审角色（场景 1/3 派遣池）

- **章仪**（章仪先生）——文种专家：公文章法仪轨，结构/要素/格式合规（"章仪"=章法仪轨）
- **笔致**（笔致先生）——风格专家：文风笔调与语料口径（"笔致"=笔法风致）
- **据实**（据实先生）——数据专家：求是/hybrid3/地方引用，据实而引、溯源不臆造
- **校书**（校书先生）——质检专家：五维质检与校勘（"校书"=古代校书郎，校对文字之官）
- **证微**（证微先生）——核查专家：考据事实、微观证伪（"证微"=从细节证是非）

## 合规专家（场景 1 涉法材料强制派遣）

- **法鉴**（法鉴先生）——合法性审查：政策依据、上位法合规性、制度衔接（能力载荷：govdoc-regulation + 政策法规库 245 篇；对应真实机构：法规处/法制办）

## 会诊专家（场景 2 派遣池；场景 6 竞稿时复用为竞稿者）

- **章策**（章策先生）——会诊专家一：文风一 政务策论视角（讲话/治理分析）
- **城构**（城构先生）——会诊专家二：文风二 城市治理叙事视角（耿彦波式）
- **枢垣**（枢垣先生）——会诊专家三：文风三 发改中枢视角（郑栅洁式/高质量发展）

## 写稿角色（场景 4-7 派遣池 · v8.1.0 新增）

- **秉笔**（秉笔先生，writer-lead）——**总纂**：定骨架契约、单点成文、缝合（"秉笔"=秉笔直书）
  - 写稿腿的**唯一执笔点**。T1 全篇由他写；T2/T4 他写首尾过渡并缝合；T3 他择优定稿。
  - 对应真实机构：业务司局拟稿人（**起草权**）。
- **分笔**（分笔先生，writer）——**笔手**：承包一个分论槽位（"分笔"=分头执笔）
  - 只写自己的槽位段落，不写别的段、不写首尾过渡、不自行缝合。
  - 对应真实机构：参与起草的相关部门。

> **佐笔不设独立角色**——写稿腿的供料岗复用评审角色：**据实**供数据要素、**法鉴**供政策依据、**笔致**供语料口径。
> 但它们在写稿腿里**只出可引用条目，不出成段正文**（供料与执笔分离，见 `team-writing.md` 第七节）。

## 派遣速查

**评审腿**：
- 场景 1（评审）派遣：文衡（主理人）+ 章仪 + 笔致 + 据实（按需）+ 校书 + 法鉴（涉法材料强制）
- 场景 2（会诊）派遣：文衡（主理人）+ 章策 + 城构 + 枢垣
- 场景 3（核查）派遣：文衡（主理人）+ 证微（复用 fact-check-team 专员）

**写稿腿**（仅显式点名）：
- 场景 4（T1 主笔+佐笔）派遣：文衡（主理人）+ **秉笔** + 佐笔按需（据实/法鉴/笔致）
- 场景 5（T2 分工承包）派遣：文衡 + **秉笔** + **分笔**×N
- 场景 6（T3 多版竞稿）派遣：文衡 + **秉笔**（择优）+ 竞稿者×N（章策/城构/枢垣）
- 场景 7（T4 分层混合）派遣：文衡 + **秉笔** + **分笔**×N + 骨架会战（多专家）

**串联**：先写（场景 4-7）→ 再审（场景 1）；秉笔不参与对自己成稿的评审。

## 备选命名（如不喜主推）

- 主理人备选：文正 / 衡文 / 执衡 / 墨卿
- 文种专家备选：章序 / 章承 ｜ 风格专家备选：风致 / 笔意 ｜ 数据专家备选：核实 / 据源
- 质检专家备选：校雠（jiao-chou，古校勘） / 审端 ｜ 核查专家备选：考实 / 察微
- 会诊三杰备选：执笔甲/乙/丙（直白型）
- **写稿角色备选**：总纂（秉笔备选，直白型） / 笔手（分笔备选，直白型）
